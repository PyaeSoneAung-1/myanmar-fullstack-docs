TypeScript က [JSX](https://www.typescriptlang.org/docs/handbook/jsx.html) ကို ထောက်ပံ့ပြီး — React codebases တွေမှာ သုံးတဲ့ `useState` လိုမျိုး patterns တွေကိုလည်း မှန်ကန်စွာ model လုပ်နိုင်ပါတယ်။

### React Project တစ်ခု Setup လုပ်ခြင်း

ဒီနေ့မှာ TypeScript ကို out of the box (ထည့်သွင်းစရာ မလိုဘဲ) ထောက်ပံ့တဲ့ frameworks တွေ အများကြီး ရှိပါတယ်:

- [Create React App](https://create-react-app.dev) — [TS docs](https://create-react-app.dev/docs/adding-typescript/)
- [Next.js](https://nextjs.org) — [TS docs](https://nextjs.org/learn/excel/typescript)
- [Gatsby](https://www.gatsbyjs.org) — [TS Docs](https://www.gatsbyjs.org/docs/typescript/)

ဒါတွေ အားလုံးက စတင်ဖို့ ကောင်းမွန်တဲ့ နေရာတွေပါ။ ကျွန်တော်တို့က [ဒီ website](https://github.com/microsoft/TypeScript-Website/) အတွက် TypeScript နဲ့တွဲပြီး [Gatsby](https://www.gatsbyjs.org/blog/2020-01-23-why-typescript-chose-gatsby/#reach-skip-nav) ကို သုံးထားပါတယ် — ဒါကြောင့် အဲဒါကလည်း အသုံးဝင်တဲ့ reference implementation တစ်ခု ဖြစ်နိုင်ပါတယ်။

### Documentation

React နဲ့ TypeScript အကြောင်း နောက်ဆုံးရ အချက်အလက်တွေ ရှာဖို့ အကောင်းဆုံး နေရာတချို့:

- [React TypeScript Cheatsheets](https://react-typescript-cheatsheet.netlify.app)
- [React & Redux in TypeScript](https://github.com/piotrwitek/react-redux-typescript-guide#react--redux-in-typescript---complete-guide)

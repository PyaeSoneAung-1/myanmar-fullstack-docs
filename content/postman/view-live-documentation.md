OpenAPI ဒါမှမဟုတ် AsyncAPI specification တစ်ခုကို တည်းဖြတ်နေတယ်ဆိုရင် — ကိုယ့် API documentation ရဲ့ live preview တစ်ခုကို Postman က ပြသပေးပါတယ်။ Specification ကို တည်းဖြတ်လိုက်တာနဲ့ — documentation preview ကိုလည်း update လုပ်ပေးပါတယ်။ အလုပ်လုပ်နေတုန်း ကိုယ့် အပြောင်းအလဲတွေကို မြင်သာအောင် ဒီ preview ကို သုံးနိုင်ပါတယ်။

[Files နဲ့ folders အများအပြားပါတဲ့](/docs/postman/add-files-to-a-specification) OpenAPI specification တစ်ခုကို တည်းဖြတ်နေတုန်း — root နဲ့ non-root files တွေအတွက်ပါ live preview တစ်ခုကိုလည်း ပြသပေးပါတယ်။

Documentation preview ကို ပြသဖို့ — ညာဘက် sidebar ထဲက ![Docs icon](https://assets.postman.com/postman-docs/aether-icons/v12/entity-docs-stroke.svg#icon) **Live preview** ကို နှိပ်ပါ။

အောက်ပါ section အမျိုးအစားတွေအတွက် live documentation ကို ကြည့်ရှုနိုင်ပါတယ်:

* **OpenAPI** — Live preview က ကိုယ့် specification ရဲ့ `Info`, `Servers` နဲ့ `Paths` sections တွေအတွက် documentation တွေကို ပြသပေးပါတယ်။ **Components** (OpenAPI 3.0 နဲ့ 3.1) နဲ့ **Definitions** (OpenAPI 2.0) sections တွေထဲက `Schemas`, `Responses` နဲ့ `Request Bodies` components တွေအတွက်လည်း live preview က documentation တွေကို ပြသပေးပါတယ်။ `Security` စတဲ့ တခြား sections တွေအတွက်တော့ preview က documentation ကို မပြသပေးပါဘူး။
* **AsyncAPI** — Live preview က ကိုယ့် specification ရဲ့ `Info`, `Servers` နဲ့ `Channels` sections တွေအတွက် documentation တွေကို ပြသပေးပါတယ်။ တခြား sections တွေအတွက်တော့ preview က documentation ကို မပြသပေးပါဘူး။

ကိုယ့် [public collections တွေကို ပြင်ဆင်ပြီး](https://learning.postman.com/docs/postman-api-network/showcase/prepare/public-collections/), [စုစည်း (curate) ပြီး](https://learning.postman.com/docs/postman-api-network/showcase/prepare/curate/overview/), [public APIs တွေကို publish လုပ်ပြီးတာနဲ့](https://learning.postman.com/docs/postman-api-network/showcase/publish/public-apis/) — *Run in Postman* button တစ်ခု ဖန်တီးပါ။ ပြီးရင် — ဒီ button ကို ကိုယ့် developer website, API reference, documentation နဲ့ public collection တစ်ခုချင်းစီရဲ့ overview pages တွေထဲမှာ ထည့်သွင်းပါ။

Run in Postman button က ကိုယ့် public APIs တွေကို ပိုပြီး ရှာဖွေတွေ့ရှိနိုင်စေပါတယ်။ API consumer တစ်ယောက်အနေနဲ့ click တစ်ချက်တည်းနဲ့ — ကိုယ့် public APIs တွေပေါ်မှာ သူတို့ရဲ့ API journey ကို စတင်နိုင်ပြီး — ပထမဆုံး 200 OK response ဆီ ရောက်ရှိနိုင်ပါတယ်။

အောင်မြင်တဲ့ API publishers တွေက — API adoption (အသုံးပြုမှု) ကို တိုးပွားစေဖို့နဲ့ ကိုယ့် API consumers တွေအတွက် developer experience ကို ပိုမိုကောင်းမွန်အောင် စီစဉ်ပေးဖို့ — Run in Postman button ကို အသုံးပြုကြပါတယ်။

API publisher ကောင်းတစ်ယောက် ဖြစ်လာဖို့ ပိုပြီး လေ့လာချင်ရင် — [Postman API Network ပေါ်မှာ ကိုယ့် public APIs တွေကို showcase လုပ်ခြင်း](https://learning.postman.com/docs/postman-api-network/showcase/overview/) ကို ကြည့်ပါ။

![Run in Postman button](https://assets.postman.com/postman-docs/v11/run-in-postman.svg)

## Run in Postman button တစ်ခု ဖန်တီးခြင်း

တစ်ယောက်ယောက်က ကိုယ့် Run in Postman button ကို click လုပ်လိုက်တဲ့အခါ — [ကိုယ့် public collection ကို fork လုပ်ဖို့](/docs/postman/forking-elements) prompt လုပ်ပေးပါတယ်။ Users တွေ ခြေလှမ်း အနည်းဆုံးနဲ့ ပထမဆုံး 200 OK response ဆီ ရောက်နိုင်အောင် — [environment](/docs/postman/managing-environments) တစ်ခုကိုလည်း ကိုယ့် collection နဲ့အတူ ထည့်သွင်းနိုင်ပါတယ်။ ဒါ့အပြင် — Postman က သူတို့ကို ကိုယ့် collection ရဲ့ [watcher](/docs/postman/collaborate-with-collections) တစ်ယောက်အနေနဲ့လည်း သတ်မှတ်ပေးတာမို့ — ကိုယ့် collection ကို update လုပ်တဲ့အခါတိုင်း သူတို့ဆီ အကြောင်းကြားချက် (notification) ရောက်ရှိပါတယ်။

အသေးစိတ် လေ့လာဖို့ — [ကိုယ့် API consumers တွေအတွက် Run in Postman button တစ်ခု ဖန်တီးခြင်း](/docs/postman/creating-run-button) ကို ကြည့်ပါ။

## ကိုယ့် Run in Postman button ကို customize လုပ်ခြင်း

ကိုယ့် API consumers တွေအတွက် developer experience ကို — custom code တွေနဲ့ ပိုပြီး စိတ်ကြိုက် ချိန်ညှိနိုင်ပါတယ်။

အသေးစိတ် လေ့လာဖို့ — [ကိုယ့် Run in Postman button ကို customize လုပ်ခြင်း](/docs/postman/customize-run-button) ကို ကြည့်ပါ။

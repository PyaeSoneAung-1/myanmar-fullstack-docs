*Postman Collections* တွေက ကိုယ့် API requests နဲ့ examples တွေကို အတူတကွ အုပ်စုဖွဲ့ စုစည်းနိုင်အောင် လုပ်ပေးပါတယ်။ Collections တွေကို သုံးပြီး — ကိုယ့် workspace ကို စနစ်ကျအောင် ထားနိုင်၊ teammates တွေနဲ့ ပူးပေါင်းလုပ်ဆောင်နိုင်၊ ပြီးတော့ API documentation နဲ့ API tests တွေကိုလည်း ဖန်တီးနိုင်ပါတယ်။ ဒါ့အပြင် — API testing လုပ်ငန်းစဉ်ရဲ့ အစိတ်အပိုင်းအနေနဲ့ request runs တွေကို automate လုပ်ဖို့လည်း collections တွေကို သုံးနိုင်ပါတယ်။

Sidebar ထဲက **Items** ကို နှိပ်ပြီး **Collections** ကို ချဲ့ကြည့်ရင် — ကိုယ့် လက်ရှိ workspace ထဲက collections တွေရဲ့ စာရင်းကို မြင်ရပါတယ်။

* Collections တွေအကြောင်း ပိုလေ့လာချင်ရင် — [Postman Collections ထဲမှာ API requests တွေကို စုစည်း automate လုပ်ခြင်း](https://learning.postman.com/docs/use/use-collections/overview/) ကို သွားပါ။
* Collections တွေ ဖန်တီးပြီး အလုပ်လုပ်ချင်ရင် — [Postman မှာ request collections တွေ ဖန်တီး စီမံခြင်း](https://learning.postman.com/docs/use/use-collections/overview/) ကို သွားပါ။
* Collection Runner သုံးနည်း လေ့လာချင်ရင် — [ကိုယ့် API ရဲ့ လုပ်ဆောင်ချက်တွေကို test လုပ်ခြင်း](https://learning.postman.com/docs/tests-and-scripts/running-collections/running-collections-overview/) ကို ကြည့်ပါ။

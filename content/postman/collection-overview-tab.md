Collection တစ်ခုရဲ့ **Overview** tab က — အဲဒီ collection ရဲ့ ရည်ရွယ်ချက်၊ မကြာသေးခင်က လုပ်ဆောင်ချက်တွေနဲ့ ဆက်စပ်နေတဲ့ elements တွေရဲ့ အကျဉ်းချုပ်ကို ပြသပေးပါတယ်။ Collaborators တွေက ဒီ tab ကို ကြည့်ပြီး — collection ရဲ့ description, မကြာသေးခင်က အပြောင်းအလဲတွေ, pinned environments, monitors, mocks နဲ့ အခြားအရာတွေကို ကြည့်နိုင်ပါတယ်။

![Collection Overview tab](https://assets.postman.com/postman-docs/v12/collection-overview-v12-01.png)

**Overview** tab မှာ အောက်ပါ collection အချက်အလက်တွေကို ကြည့်နိုင်ပါတယ်:

* **Description** — Collection ဆိုတာ ဘာလဲ၊ ဘယ်လို အသုံးပြုနိုင်လဲ ဆိုတာကို ရှင်းပြပေးပါတယ်။ ပိုလေ့လာချင်ရင် — [Collection တစ်ခုမှာ descriptions တွေ ထည့်ခြင်း](https://learning.postman.com/docs/publishing-your-api/document-a-collection/#add-descriptions-to-a-collection) ကို ကြည့်ပါ။

* **View complete documentation** — Collection ရဲ့ [documentation](https://learning.postman.com/docs/publishing-your-api/document-a-collection/) အပြည့်အစုံကို ကြည့်ဖို့ နှိပ်ပါ။

* **Collection details** — Collection အကြောင်း အချက်အလက်တွေကို ကြည့်နိုင်ပါတယ်၊ ဥပမာ:
  * Collection ကို ဖန်တီးခဲ့တဲ့ user။
  * Collection ထဲမှာ ပါဝင်တဲ့ [requests](/docs/postman/requests) (![Request icon](https://assets.postman.com/postman-docs/aether-icons/v12/entity-request-stroke.svg#icon)) အရေအတွက်။
  * Collection ကို ကြည့်ရှုခဲ့တဲ့ အကြိမ်အရေအတွက် views (![Report icon](https://assets.postman.com/postman-docs/aether-icons/v12/descriptive-report-stroke.svg#icon))။
  * Collection ရဲ့ နောက်ဆုံး update လုပ်ခဲ့တဲ့ ရက်စွဲနဲ့ အချိန်။ ရက်စွဲကို နှိပ်ရင် collection ရဲ့ [changelog](/docs/postman/manage-collections) ကို ကြည့်နိုင်ပါတယ်။
  * Collection ရဲ့ specification။ Specification ရဲ့ နာမည်ကို နှိပ်ရင် generated specification ကို ကြည့်နိုင်ပါတယ်။ ပိုလေ့လာချင်ရင် — [Collection တစ်ခုကနေ API specification တစ်ခု generate လုပ်ခြင်း](https://learning.postman.com/docs/design-apis/collections/generate-specifications/) ကို ကြည့်ပါ။

* **Status and Tags** — Collection မှာ သတ်မှတ်ထားတဲ့ [tags](/docs/postman/collaborate-with-collections) နဲ့ [status](/docs/postman/collaborate-with-collections) တွေရဲ့ စာရင်းကို ပြပါတယ်။

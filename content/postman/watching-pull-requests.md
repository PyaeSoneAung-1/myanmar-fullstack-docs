Watch option က — team member တစ်ယောက်က pull request ကို ပြင်ဆင်တဲ့အခါ in-app notification တစ်ခု ရရှိစေပါတယ်။ Pull request တစ်ခုကို watch လုပ်ထားရင် — comment အသစ်တစ်ခု ထည့်ခြင်း, approval ပေးခြင်း ဒါမှမဟုတ် approval ရုပ်သိမ်းခြင်း, merge လုပ်ခြင်း နဲ့ pull request တစ်ခုကို တည်းဖြတ်ခြင်း ဒါမှမဟုတ် decline လုပ်ခြင်း စတဲ့ လုပ်ဆောင်ချက်တွေအကြောင်း notifications တွေ ရရှိပါလိမ့်မယ်။

## Pull request တစ်ခုကို watch လုပ်ခြင်း

Pull request တစ်ခုကို watch လုပ်ဖို့ — pull request ထဲမှာ **Watch** ကို နှိပ်ပါ။

## Watch notifications settings တွေ ပြောင်းလဲခြင်း

1. Pull request ထဲမှာ **Watch** ကို နှိပ်ပါ။
2. လိုချင်တဲ့ notification options တွေကို ရွေးပါ ဒါမှမဟုတ် ရွေးထားတာတွေကို ဖျက်ပါ။

## Notifications တွေကို ကြည့်ရှုခြင်း

Watch လုပ်ထားတဲ့ pull request တစ်ခုရဲ့ notifications တွေကို ကြည့်ဖို့ — Postman header ထဲက **Notifications** ကို နှိပ်ပါ။ Popup က pull request ဆီက အပြောင်းအလဲတွေအကြောင်း နောက်ထပ် အချက်အလက်တွေကို ဖော်ပြပါတယ်။

ကိုယ်တိုင် pull request တစ်ခုကို ဖန်တီးပြီး — Postman account တစ်ခုတည်းကနေ အဲဒီ pull request ကို ပြင်ဆင်မယ်ဆိုရင် — pull request ဆီ လုပ်တဲ့ အပြောင်းအလဲတွေအကြောင်း notifications တွေ ဘာမှ ရရှိမှာ မဟုတ်ပါဘူး။

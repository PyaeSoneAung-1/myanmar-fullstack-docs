ဒီ feature ကို Postman Enterprise plans တွေမှာ ရနိုင်ပါတယ်။ အသေးစိတ်ကို [pricing page](https://www.postman.com/pricing/) မှာ ကြည့်ပါ။

ကိုယ့် *Private API Network* ဆိုတာ — ကိုယ့် organization ရဲ့ internal workspaces တွေထဲက team အလိုက် စနစ်တကျ ရွေးချယ်ထားတဲ့ အစိတ်အပိုင်းတစ်ခု ဖြစ်ပါတယ်။ အဲဒီမှာ ကိုယ့် အလုပ်နဲ့ အသက်ဆိုင်ဆုံး internal APIs တွေကို ရှာဖွေတွေ့ရှိနိုင်ပါတယ်။

ကောင်းစွာ စနစ်တကျ ပြုစုထားတဲ့ Private API Network တစ်ခုနဲ့ — ကိုယ့် organization ရဲ့ အရေးအကြီးဆုံး internal workspaces, collections နဲ့ internal APIs တွေကို ထင်ရှားအောင် ပြသနိုင်ပါတယ်။ ကိုယ့် organization က အကောင်းဆုံး အလုပ်တွေ လုပ်ဆောင်ဖို့ သုံးနိုင်တဲ့ Postman elements တွေကို ရှာဖွေတွေ့ရှိဖို့ ကူညီပေးပါ။

## ကိုယ့် Private API Network ကို ရှာဖွေခြင်း

ကိုယ့် organization ရဲ့ အရေးအကြီးဆုံး internal APIs တွေကို ရှာဖွေဖို့ — ကိုယ့် Private API Network ထဲမှာ ရှာဖွေ ဒါမှမဟုတ် ကြည့်ရှုနိုင်ပါတယ်။ အဲဒီမှာ ကိုယ့် အလုပ်နဲ့ အသက်ဆိုင်ဆုံး Postman elements တွေကို ရှာဖွေတွေ့ရှိနိုင်ပါတယ်။

အသေးစိတ်ကို [ကိုယ့် organization ရဲ့ Private API Network ကို ရှာဖွေခြင်း](https://learning.postman.com/docs/collaborating-in-postman/private-api-network/explore/) မှာ ကြည့်ပါ။

## ကိုယ့် Private API Network ကို စီမံခန့်ခွဲခြင်း

ကိုယ့် organization ရဲ့ အရေးအကြီးဆုံး internal APIs တွေကို ပိုမို ရှာဖွေတွေ့ရှိနိုင်စေဖို့ — ကိုယ့် Private API Network ကို စနစ်တကျ ပြုစုပါ။ ကိုယ့် role ပေါ်မူတည်ပြီး — Private API Network ထဲ workspaces တွေကို ထည့်နိုင်သလို ဒါမှမဟုတ် ထည့်ဖို့ request လုပ်နိုင်ပါတယ်။

အသေးစိတ်ကို [ကိုယ့် organization ရဲ့ Private API Network ကို စီမံခန့်ခွဲခြင်း](https://learning.postman.com/docs/collaborating-in-postman/private-api-network/manage/) မှာ ကြည့်ပါ။

## ကိုယ့် Private API Network ကို migrate လုပ်ခြင်း

Private API Network ရဲ့ အစောပိုင်း version တစ်ခုကို သုံးနေပြီး — နောက်ဆုံး version ကို သုံးချင်တယ်ဆိုရင် migrate လုပ်ရပါမယ်။

အသေးစိတ်ကို [ကိုယ့် organization ရဲ့ Private API Network ကို migrate လုပ်ခြင်း](https://learning.postman.com/docs/collaborating-in-postman/private-api-network/migrate/) မှာ ကြည့်ပါ။

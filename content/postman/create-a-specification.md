ဒီ guide ထဲက ညွှန်ကြားချက်တွေကို လိုက်နာပြီး — ကိုယ့် API ရဲ့ တည်ဆောက်ပုံကို ဒီဇိုင်းလုပ်ဖို့နဲ့ test လုပ်ဖို့ [Spec Hub မှာ specification တစ်ခု ဖန်တီး](#specification-အသစ်တစ်ခု-ဖန်တီးခြင်း)နိုင်ပါတယ်။ OpenAPI, AsyncAPI, protobuf, GraphQL နဲ့ Smithy [format](/docs/postman/specifications-overview) တွေနဲ့ specifications တွေကို ဖန်တီးနိုင်ပြီး — ကိုယ့် specification ပေါ်မှာ [တခြားသူတွေနဲ့ ပူးပေါင်းဆောင်ရွက်](/docs/postman/collaborate-with-specifications)နိုင်ပါတယ်။

Spec Hub ထဲကို [specification တစ်ခု import လုပ်](/docs/postman/import-a-specification)တာလည်း လုပ်နိုင်ပါတယ်။

## Specification အသစ်တစ်ခု ဖန်တီးခြင်း

Spec Hub မှာ OpenAPI, AsyncAPI, protobuf နဲ့ GraphQL specifications တွေကို ဖန်တီးနိုင်ပါတယ်။ ရှိပြီးသား [specification တစ်ခုကို Postman ထဲကို import လုပ်](/docs/postman/import-a-specification)တာလည်း လုပ်နိုင်ပါတယ်။

1. Sidebar ထဲမှာ ![Add icon](https://assets.postman.com/postman-docs/aether-icons/v12/action-add-stroke.svg#icon) ကို နှိပ်ပြီး **Spec** ကို ရွေးပါ။
2. ဖန်တီးချင်တဲ့ specification အမျိုးအစားကို ရွေးပါ။ Postman က boilerplate content တွေနဲ့အတူ specification အသစ်တစ်ခု ဖန်တီးပေးပါတယ်။
3. Specification ကို နာမည်ပြောင်းချင်ရင် — sidebar ထဲက specification ဘေးက ![Options icon](https://assets.postman.com/postman-docs/aether-icons/v12/action-options-stroke.svg#icon) **More actions** ကို နှိပ်ပြီး **Rename** ကို ရွေးပါ။ နာမည်အသစ် ရိုက်ထည့်ပြီး **Return** ဒါမှမဟုတ် **Enter** ကို နှိပ်ပါ။ ဒါမှမဟုတ် — workbench ထဲက file name ကို ရွေးပြီး နာမည်အသစ် ရိုက်ထည့်ကာ **Return** ဒါမှမဟုတ် **Enter** ကို နှိပ်ပါ။
4. ကိုယ့် API အတွက် လိုအပ်သလို specification ထဲက content တွေကို တည်းဖြတ်ပါ ဒါမှမဟုတ် အစားထိုးပါ။ [ကိုယ့် specification ကို တည်းဖြတ်ခြင်း](/docs/postman/edit-a-specification) အကြောင်း ပိုလေ့လာပါ။

ကိုယ့် [Postman plan](https://www.postman.com/pricing/) က ကိုယ့် team ရဲ့ internal workspaces တွေမှာ specifications အရေအတွက် အကန့်အသတ်တစ်ခုပဲ ပေးပါတယ်။ [Postman မှာ resource usage အကြောင်း](https://learning.postman.com/docs/billing/resource-usage/#specifications) ပိုလေ့လာပါ။

Specification တစ်ခု ဖန်တီးပြီးတာနဲ့ — အဲဒီ specification ရဲ့ အမျိုးအစားကို ပြောင်းလို့ မရပါဘူး။ Specification အသစ်တစ်ခု ဖန်တီးရပါမယ်။

## Specification တစ်ခုကို နာမည်ပြောင်းခြင်း

1. Sidebar ထဲက **Specs** ကို ချဲ့ပါ။
2. ကိုယ့် specification ဘေးက ![Options icon](https://assets.postman.com/postman-docs/aether-icons/v12/action-options-stroke.svg#icon) **More actions > Rename** ကို ရွေးပါ။
3. Specification အတွက် နာမည်အသစ် ရိုက်ထည့်ပါ။
4. **Return** ဒါမှမဟုတ် **Enter** ကို နှိပ်ပါ။

## Specification တစ်ခုကို ဖျက်ခြင်း

1. Sidebar ထဲက **Specs** ကို ချဲ့ပါ။
2. ကိုယ့် specification ဘေးက ![Options icon](https://assets.postman.com/postman-docs/aether-icons/v12/action-options-stroke.svg#icon) **More actions > Delete** ကို ရွေးပါ။
3. အတည်ပြုဖို့ **Delete** ကို နှိပ်ပါ။

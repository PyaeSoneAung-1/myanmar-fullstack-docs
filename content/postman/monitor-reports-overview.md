Published monitor reports တွေကို Postman Solo, Team နဲ့ Enterprise plans တွေမှာ ရနိုင်ပါတယ်။ အသေးစိတ်အတွက် — [pricing page](https://www.postman.com/pricing/) ကို ကြည့်ပါ။

Monitor reports တွေနဲ့ဆိုရင် — ကိုယ့် monitor results တွေရဲ့ read-only view တစ်ခုကို publish လုပ်ပြီး public link တစ်ခုနဲ့ မျှဝေနိုင်ပါတယ်။ Published monitor reports တွေက — viewers တွေ Postman ထဲကို sign in လုပ်စရာ ဒါမှမဟုတ် ကိုယ့် workspace ကို ဝင်ရောက်ခွင့် မလိုဘဲ — API uptime, performance နဲ့ မကြာသေးခင်က run results တွေကို ပြသပေးပါတယ်။

စတင်ဖို့ — ကိုယ့် internal team ဒါမှမဟုတ် public workspace ထဲက monitor တစ်ခုကနေ monitor report တစ်ခုကို publish လုပ်ပါ။ Publish လုပ်ပြီးတာနဲ့ — ကိုယ့် monitors တွေဆီကို တိုက်ရိုက် access မပေးဘဲ API ယုံကြည်စိတ်ချရမှုကို ဆက်သွယ်ပြောဆိုဖို့ — link ကို stakeholders တွေနဲ့ မျှဝေနိုင်ပါတယ်။

## Monitor report တစ်ခု publish လုပ်ခြင်း

Monitor တစ်ခုအတွက် — ၎င်းရဲ့ results တွေကို ပြင်ပမှာ မျှဝေဖို့ public, read-only report တစ်ခု ဖန်တီးပါ။ Report ကို title နဲ့ description တစ်ခုနဲ့ customize လုပ်နိုင်ပြီး — request endpoints တွေ ပြသမလား ရွေးချယ်နိုင်ပါတယ်။

[Monitor reports တွေ publish လုပ်ခြင်း](/docs/postman/publish-monitor-reports) မှာ ပိုလေ့လာပါ။

## Published monitor report တစ်ခုကို ကြည့်ရှုခြင်း

မကြာသေးခင်က monitor runs တွေ, health status နဲ့ request-level အသေးစိတ်တွေကို ကြည့်ဖို့ — published monitor report တစ်ခုကို ၎င်းရဲ့ shared link နဲ့ ဖွင့်ပါ။

[Published monitor report တစ်ခုကို ကြည့်ရှုခြင်း](/docs/postman/publish-monitor-reports#published-monitor-report-တစ်ခုကို-ကြည့်ရှုခြင်း) မှာ ပိုလေ့လာပါ။

## Monitor report တစ်ခုကို update ဒါမှမဟုတ် unpublish လုပ်ခြင်း

ရှိပြီးသား published monitor report တစ်ခုကို ပြုပြင်နိုင်သလို — လုံးဝ ဖယ်ရှားလို့လည်း ရပါတယ်။ Report ရဲ့ title, description နဲ့ visibility settings တွေကို update လုပ်နိုင်သလို — မလိုအပ်တော့ဘူးဆိုရင် unpublish လုပ်နိုင်ပါတယ်။

[Monitor reports တွေ update လုပ်ခြင်း](/docs/postman/update-monitor-reports) မှာ ပိုလေ့လာပါ။

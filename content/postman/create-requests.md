Postman API client ကို သုံးပြီး ကိုယ်က build လုပ်နေတဲ့၊ test လုပ်နေတဲ့ ဒါမှမဟုတ် integrate လုပ်နေတဲ့ APIs တွေဆီ ချိတ်ဆက်လို့ရပါတယ်။ Parameters, body data နဲ့ headers တွေပါတဲ့ API requests တွေကို ဖန်တီးပြီး ပို့နိုင်ပါတယ်။ Requests တွေကို collections ထဲမှာ သိမ်းထားနိုင်ပြီး — team နဲ့ ပူးပေါင်းလုပ်ဆောင်ဖို့ ဒါမှမဟုတ် automated testing မှာ သုံးဖို့ပါ။

## Postman မှာ API requests တွေ build လုပ်ခြင်း

Postman ကို သုံးပြီး HTTP ဒါမှမဟုတ် GraphQL, gRPC, WebSocket စတဲ့ အခြား common protocols တွေနဲ့ [API requests တွေကို ဖန်တီးပြီး ပို့လို့ရပါတယ်](https://learning.postman.com/docs/use/send-requests/create-requests/request-basics/)။ API ရဲ့ လိုအပ်ချက်အရ [parameters နဲ့ body data တွေ ပို့နိုင်သလို](https://learning.postman.com/docs/use/send-requests/create-requests/parameters/) [request headers တွေလည်း ပို့နိုင်ပါတယ်](https://learning.postman.com/docs/use/send-requests/create-requests/headers/)။ [Request တစ်ခုစီအတွက် custom settings တွေလည်း configure လုပ်နိုင်ပါတယ်](https://learning.postman.com/docs/use/send-requests/create-requests/request-settings/)။

## Team ထဲ test data တွေ upload လုပ်ခြင်း

Postman က ကိုယ့် Postman team ထဲက တခြားသူတွေနဲ့ test data တွေကို share လုပ်နိုင်အောင် လုပ်ပေးပါတယ်။ [Data files တွေကို team ထဲ upload လုပ်ထားနိုင်ပြီး](https://learning.postman.com/docs/use/send-requests/create-requests/test-data/) — team ဝင် ဘယ်သူမဆို Postman မှာ request ပို့တဲ့အခါ အဲဒီ uploaded files တွေကို form data ဒါမှမဟုတ် raw body data အဖြစ် သုံးနိုင်ပါတယ်။

## Postman Collections နဲ့ requests တွေကို စုစည်းခြင်း

[API requests တွေကို collections ထဲမှာ သိမ်းပြီး စုစည်းထားနိုင်လို့](https://learning.postman.com/docs/use/send-requests/create-requests/intro-to-collections/) အကြိမ်ကြိမ် ပြန်သုံးနိုင်ပါတယ်။ Team နဲ့ ပူးပေါင်းလုပ်ဆောင်ဖို့၊ API tests နဲ့ documentation တွေ ထုတ်ဖို့၊ request ပို့ခြင်းကို automate လုပ်ဖို့ collections တွေကို သုံးပါတယ်။

## Requests ကနေ code snippets ထုတ်ခြင်း

Postman က ကိုယ့် front-end application ကို API နဲ့ ချိတ်ဆက်ဖို့ ကူညီပေးနိုင်ပါတယ်။ Postman CLI, C#, JavaScript, NodeJS စတဲ့ supported language တစ်ခုကို ရွေးပြီး [request တစ်ခုကနေ code snippet တစ်ခု ထုတ်လို့ရပါတယ်](https://learning.postman.com/docs/use/send-requests/create-requests/generate-code-snippets/)။ App ထဲမှာ API ကို ခေါ်ဖို့ အဲဒီ snippet ကို သုံးနိုင်ပါတယ်။

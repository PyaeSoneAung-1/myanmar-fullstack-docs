APIs တချို့က requests တွေနဲ့အတူ တိကျတဲ့ headers တွေ ပို့ဖို့ လိုအပ်ပါတယ် — ကိုယ် လုပ်ဆောင်နေတဲ့ operation အကြောင်း metadata (နောက်ခံ အချက်အလက်) ပေးဖို့ပါ။ Postman မှာ request headers တွေကို configure လုပ်နိုင်ပြီး — headers အုပ်စုတွေကို presets အနေနဲ့ သိမ်းထားပြီး အမြန် ပြန်သုံးနိုင်ပါတယ်။ Request မှာ ကိုယ်ရွေးချယ်ထားတဲ့အရာတွေပေါ် မူတည်ပြီး — Postman က headers တွေကိုလည်း လိုအပ်သလို requests တွေထဲ အလိုအလျောက် ထည့်ပေးပါတယ်။

## Request headers သတ်မှတ်ခြင်း

Request ရဲ့ **Headers** tab ထဲမှာ headers တွေကို configure လုပ်နိုင်ပါတယ်။ လိုအပ်တဲ့ key-value အတွဲတွေ ထည့်လိုက်ရင် — Postman က request နဲ့အတူ ပို့ပေးပါတယ်။ Text ရိုက်နေတုန်း Postman က `Content-Type` လိုမျိုး အသုံးများတဲ့ option တွေကို အကြံပြုပြပြီး — ကိုယ့် setup ကို autocomplete (အလိုအလျောက် ဖြည့်ပေးခြင်း) လုပ်နိုင်အောင် ကူညီပေးပါတယ်။

Headers တွေ သတ်မှတ်ပြီးတာနဲ့ **Send** ကို ရွေးပြီး request ကို ပို့လိုက်ပါ။ [Postman မှာ requests တွေ ဖန်တီး ပို့ခြင်း](https://learning.postman.com/docs/use/send-requests/create-requests/request-basics/) အကြောင်း ဆက်လေ့လာနိုင်ပါတယ်။

## Header presets

အသုံးများတဲ့ headers တွေကို *header preset* (ကြိုသိမ်းထားတဲ့ header အစုအဝေး) တစ်ခုထဲမှာ အတူတူ သိမ်းထားနိုင်ပါတယ်။ Request ရဲ့ **Headers** tab ထဲမှာ — **Presets** dropdown list ကို ရွေးပြီး **Manage Presets** ကို ရွေးပါ။ Preset အသစ်တစ်ခု ထည့်ဖို့ **Add Header Preset** ကို ရွေးပြီး — preset ရဲ့ နာမည်တစ်ခု ထည့်ပါ။ Key-value အတွဲတွေ ထည့်ပြီးတာနဲ့ **Add** ကို ရွေးပါ။

**Presets** dropdown list ထဲကနေ ကိုယ့် preset ကို ရွေးနိုင်ပါတယ်။ Preset ကို ရွေးလိုက်တာနဲ့ — request headers ထဲက fields တွေကို အလိုအလျောက် ဖြည့်ပေးပါတယ်။

## Autogenerated headers (Postman က အလိုအလျောက် ထည့်ပေးတဲ့ headers)

Postman က request မှာ ကိုယ်ရွေးချယ်ထားတဲ့အရာတွေနဲ့ settings တွေပေါ် မူတည်ပြီး — headers တချို့ကို requests တွေထဲ အလိုအလျောက် ထည့်ပေးပါတယ်။ Request ရဲ့ **Headers** tab ရဲ့ ထိပ်မှာရှိတဲ့ **hidden** ကို ရွေးပြီး — Postman က request နဲ့အတူ ဘာတွေ ပို့မယ်ဆိုတဲ့ အချက်အလက်ကို ကြည့်နိုင်ပါတယ်။

Header တစ်ခုပေါ်မှာ hover လုပ်ပြီး — အဲဒီ header အကြောင်း အသေးစိတ် ကြည့်နိုင်ပါတယ်။ Postman က ဒီ header ကို ဘာကြောင့် ထည့်ထားလဲဆိုတာ ညွှန်ပြပေးပြီး — လိုအပ်ရင် header value တစ်ခုကို ဘယ်လို deactivate (ရပ်တန့်) ဒါမှမဟုတ် override (အစားထိုး) လုပ်ရမလဲဆိုတာကိုလည်း ဖော်ပြပါတယ်။

Header တစ်ခုကို **Authorization** tab, request ရဲ့ **Body**, request ပို့တဲ့ domain အတွက် **Cookies**, **Settings** — ဒါတွေထဲက နေရာတွေမှာ ပြောင်းလဲလို့ရပြီး — တချို့ကိစ္စတွေမှာတော့ **Headers** tab ထဲမှာ ကိုယ်တိုင် ပြောင်းလို့ရပါတယ်။ App ရဲ့ တခြားအပိုင်းကို သွားဖို့ လိုအပ်ရင် — Postman က right-hand side မှာ link တစ်ခု ပြပေးပါတယ်။

Auth setup ကြောင့် ထည့်လိုက်တဲ့ header တစ်ခုဆိုရင် — အဲဒါကို ပြောင်းလဲဖို့ [**Authorization** tab ကို ရွေးပါ](/docs/postman/authorization)။ Cookie headers တွေ ပြောင်းလဲချင်ရင် — request ပို့တဲ့ domain အတွက် [cookie setup ကို ပြောင်းပါ](https://learning.postman.com/docs/use/send-requests/response-data/cookies/)။

**Headers** tab ထဲမှာ autogenerated header တစ်ခုကို deactivate လုပ်ချင်ရင် — သူ့ရဲ့ checkbox ကို ရှင်းလိုက်ပါ (uncheck)။ Autogenerated header value တစ်ခုကို override လုပ်ချင်ရင် — autogenerated entry ဘေးက checkbox ကို ရှင်းပြီး — အဲဒီ header အတွက် entry တစ်ခု သပ်သပ် ထပ်ထည့်ပါ: **Key** field ထဲမှာ header ရဲ့ name ကို ရေးပြီး **Value** field ထဲမှာ ကိုယ့် value ကို သတ်မှတ်ပါ။

Header တစ်ခုတည်းအတွက် entry တစ်ခုထက်ပို ရှိနေရင် — ဘယ်ဟာက override ဖြစ်မယ်ဆိုတာ Postman က ညွှန်ပြပါတယ်။ **Headers** ထဲမှာ ကိုယ်တိုင် တိုက်ရိုက် ထည့်ထားတဲ့ headers တွေကို ဒါမှမဟုတ် — **Authorization** လိုမျိုး request ရဲ့ တခြားအပိုင်းတွေမှာ ရွေးချယ်မှုတွေကြောင့် သွယ်ဝိုက်ပြီး ထည့်ထားတဲ့ headers တွေကို Postman က ဦးစားပေးပါတယ်။

`Content-Length` နဲ့ `Content-Type` headers တွေအတွက်တော့ — Postman က request ပို့တဲ့အခါ **Body** tab ထဲက data ပေါ် မူတည်ပြီး တန်ဖိုးတွေကို အလိုအလျောက် တွက်ချက်ပေးပါတယ်။ ဒါပေမယ့် value နှစ်ခုလုံးကို override လုပ်လို့တော့ ရပါတယ်။

Postman ရဲ့ sidebar ကနေ WebSocket request တစ်ခု ဖန်တီးနိုင်ပါတယ်။

1. Tab အသစ်တစ်ခုမှာ raw WebSocket request တစ်ခု ဖွင့်ဖို့ — **New > WebSocket** ကို နှိပ်ပါ။ Tab အသစ်တစ်ခုမှာ [Socket.IO request](https://learning.postman.com/docs/use/send-requests/protocols/websocket/create-a-socketio-request/) တစ်ခု ဖွင့်ဖို့ဆိုရင် — **New > Socket.IO** ကိုလည်း နှိပ်နိုင်ပါတယ်။ (Postman desktop app မှာဆိုရင် — **⌘+N** ဒါမှမဟုတ် **Ctrl+N** ကိုလည်း နှိပ်နိုင်ပါတယ်။)

   ![New WebSocket request](https://assets.postman.com/postman-docs/v12/websocket-requests-3-12-26-v12.png)

2. WebSocket server ရဲ့ URL ကို ရိုက်ထည့်ပါ။ WebSocket URL တစ်ခုက `ws://` ဒါမှမဟုတ် `wss://` နဲ့ စပါတယ်။

   ![New WebSocket request](https://assets.postman.com/postman-docs/v11/websocket-server-url-v11-62.png)

3. **Connect** ကို နှိပ်ပါ။

WebSocket request ရဲ့ ချိတ်ဆက်မှုကို ဖြုတ်ချင်ရင် — **Disconnect** ကို နှိပ်ပါ။

Postman web app ကို သုံးနေတယ်ဆိုရင် — အကောင်းဆုံး အတွေ့အကြုံအတွက် Postman Desktop Agent ကို သုံးဖို့ စဉ်းစားပါ။ [Postman Agent အကြောင်း](https://learning.postman.com/docs/getting-started/basics/about-postman-agent/) မှာ ပိုပြီး သိရှိနိုင်ပါတယ်။

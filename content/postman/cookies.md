Postman ရဲ့ cookie manager က domain အမျိုးမျိုးနဲ့ ဆက်စပ်နေတဲ့ cookies တွေကို ကြည့်ရှုပြီး တည်းဖြတ်နိုင်အောင် လုပ်ပေးပါတယ်။ Domain တစ်ခုအတွက် cookies တွေကို ကိုယ်တိုင် ဖန်တီးနိုင်သလို — Postman proxy ဒါမှမဟုတ် Postman Interceptor ကို သုံးပြီး [cookies တွေကို capture လုပ်နိုင်ပါတယ်](https://learning.postman.com/docs/use/capturing-request-data/syncing-cookies/)။ ပြီးရင် Postman မှာ requests တွေ ပို့တဲ့အခါ — Postman cookie jar ထဲမှာ သိမ်းထားတဲ့ cookies တွေကို သုံးနိုင်ပါတယ်။

Request တစ်ခုနဲ့အတူ cookies တွေ ပို့တာကို ပိတ်ချင်ရင် — request ရဲ့ **Settings** tab ကို ရွေးပြီး **Disable cookie jar** ကို ရွေးပါ။

## Cookies အကြောင်း

*cookie* ဆိုတာ — computer တစ်ခုက လက်ခံရရှိပြီး ပြောင်းလဲခြင်း မရှိဘဲ ပြန်ပို့ပေးတဲ့ data အစုအဝေး (packet) တစ်ခု ဖြစ်ပါတယ်။ Cookie အများစုမှာ data နှစ်ပိုင်း ပါဝင်ပါတယ် — user တစ်ယောက်ချင်းစီအတွက် unique ID တစ်ခုနဲ့ site နာမည်တစ်ခုပါ။

Websites တွေက ကိုယ် ပြန်လည်ဝင်ရောက်ကြည့်ရှုတဲ့အခါ cookie ကို ပြန်ယူပြီး — ကိုယ့်ကို မှတ်မိစေကာ ကိုယ့်ရဲ့ preferences တွေပေါ် အခြေခံပြီး page content တွေကို စိတ်ကြိုက် ပြင်ဆင်ပေးနိုင်ပါတယ်။ Cookies တွေ မရှိဘူးဆိုရင် — site တစ်ခုကနေ ထွက်သွားတဲ့အခါတိုင်း နောက်တစ်ကြိမ် ပြန်ဝင်ဖို့ sign in ပြန်လုပ်ရမှာ ဖြစ်သလို၊ web page တစ်ခု ပိတ်လိုက်ရင် shopping cart ကိုလည်း ပြန်တည်ဆောက်ရမှာ ဖြစ်ပါတယ်။ ဒါကြောင့် cookies တွေက internet အတွေ့အကြုံရဲ့ အရေးပါတဲ့ အစိတ်အပိုင်း တစ်ခု ဖြစ်ပါတယ်။

## Cookie manager ကို သုံးခြင်း

Postman မှာ cookies တွေကို စီမံခန့်ခွဲဖို့ — request တစ်ခု ဖွင့်ပြီး (**Send** အောက်မှာရှိတဲ့) **Cookies** ကို ရွေးပါ။

**Cookies** window ထဲမှာ **Manage Cookies** tab ကို ရွေးရင် — domains တွေနဲ့ domain တစ်ခုချင်းစီနဲ့ ဆက်စပ်နေတဲ့ cookies တွေရဲ့ စာရင်း ပြသပေးပါတယ်။ စာရင်းထဲမှာ မပါတဲ့ domain တစ်ခုရဲ့ cookies တွေကို ကြည့်ချင်ရင် — [domain တစ်ခု ထည့်နိုင်ပါတယ်](#domain-တစ်ခု-ထည့်ခြင်း)။

## Domain တစ်ခု ထည့်ခြင်း

Cookie manager ထဲကို domain အသစ်တစ်ခု ထည့်ဖို့ —

1. **Type a domain name** text box ထဲမှာ domain နာမည်ကို ရိုက်ထည့်ပါ။ Protocol (ဥပမာ `http://`) ဒါမှမဟုတ် port number တစ်ခု ထည့်လိုက်ရင် — cookie manager ထဲမှာ domain နာမည်နဲ့အတူ သိမ်းဆည်းမှာ မဟုတ်ပါဘူး။
2. **Add domain** ကို နှိပ်ပါ။

## Cookies ဖန်တီးခြင်း

Domain တစ်ခုအတွက် cookie အသစ်တစ်ခု ထည့်ဖို့ —

1. Domain အောက်မှာ **Add cookie** ကို နှိပ်ပါ။ [HTTP State Management standards](https://datatracker.ietf.org/doc/html/rfc6265#section-4.1) နဲ့ ကိုက်ညီတဲ့ pre-generated cookie string တစ်ခု ဖန်တီးပေးပါတယ်။

   ```js
   Cookie_1=value; Path=/; Expires=Wed, 09 Oct 2024 21:49:26 GMT;
   ```

   Postman က အောက်ပါ attributes တွေကို support လုပ်ပါတယ်:

   * **cookieName** = **cookieValue** — cookie ရဲ့ နာမည်နဲ့ သိမ်းထားတဲ့ value။
   * **Domain** — Postman က cookie ကို ပို့ပေးမယ့် domain။
   * **Path** — cookie ကို ကန့်သတ်ထားတဲ့ URL path။ Path က `/` ဖြစ်ရင် — သတ်မှတ်ထားတဲ့ domain ထဲက requests အားလုံးဆီကို cookie ပို့ပေးပါတယ်။
   * **HttpOnly** — ပါဝင်နေရင် — page ပေါ်မှာ run နေတဲ့ client-side scripts တွေ (ဥပမာ JavaScript ထဲက `document.cookie`) အတွက် cookie ကို မရနိုင်အောင် လုပ်ပေးပါတယ်။ Cookie ကို လုပ်ဆောင်တဲ့ requests တွေရဲ့ cookie header ထဲမှာပဲ ထည့်ပေးမှာ ဖြစ်ပါတယ်။ ဒီ field က Postman ရဲ့ အပြုအမူအပေါ် သက်ရောက်မှု မရှိပါဘူး။
   * **Secure** — ပါဝင်နေရင် — URL က `https://` နဲ့ စတင်တဲ့အခါမှာပဲ cookie ကို ပို့ပြီး — လုံခြုံမှု မရှိတဲ့ connection တွေကနေ ပို့မှာ မဟုတ်ပါဘူး။
   * **Expires** — ဒီအချိန်နောက်ပိုင်းမှာ cookie က expire ဖြစ်ပြီး — Postman က မပို့တော့ပါဘူး။

2. Cookie ကို သက်ဆိုင်ရာ domain အောက်က Postman cookie jar ထဲမှာ သိမ်းဖို့ **Save** ကို နှိပ်ပါ။

Postman က `SameSite` attribute ဒါမှမဟုတ် `__Secure-` နဲ့ `__Host-` prefixes တွေကို support မလုပ်ပါဘူး။

Response တစ်ခုထဲက cookies တွေကို [Set-Cookie header](https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/Set-Cookie) နဲ့လည်း ထည့်သွင်း/တည်းဖြတ်နိုင်ပါတယ်။

## Cookies တွေကို တည်းဖြတ်ခြင်း သို့မဟုတ် ဖျက်ခြင်း

Domain တစ်ခုအတွက် ရှိပြီးသား cookie တစ်ခုကို update လုပ်ဖို့ — တည်းဖြတ်ချင်တဲ့ cookie ကို နှိပ်ပြီး attribute တစ်ခုခုကို ပြင်ကာ **Save** ကို နှိပ်ပါ။

Domain တစ်ခုနဲ့ သူနဲ့ ဆက်စပ်နေတဲ့ cookies အားလုံးကို ဖျက်ဖို့ — domain နာမည်ဘေးက close (ပိတ်) icon ကို နှိပ်ပါ။ Cookie တစ်ခုချင်းစီကို ဖျက်ဖို့ကတော့ — cookie ဘေးက close icon ကို နှိပ်ပါ။

Postman cookie jar ထဲက cookies နဲ့ domains အားလုံးကို ဖယ်ရှားဖို့ — **Clear all cookies** ကို နှိပ်ပါ။

## Request တစ်ခုနဲ့အတူ cookies ပို့ခြင်း

Cookie တစ်ခု ထည့်ထားတဲ့ domain တစ်ခုဆီ request တစ်ခု လုပ်တဲ့အခါ — cookie က request ရဲ့ **Headers** tab ထဲမှာ အလိုအလျောက် ပေါ်လာပါတယ်။ Cookie မပေါ်ဘူးဆိုရင် — autogenerated headers တွေကို ပြသဖို့ **hidden** ကို နှိပ်ပါ။

**Headers** tab ထဲမှာ cookie headers တွေကို တိုက်ရိုက် override လုပ်လို့ မရပါဘူး။ Cookie manager ထဲမှာ cookie ကို တည်းဖြတ်ပါ၊ ဒါမှမဟုတ် cookie ကို ဖျက်ပြီး request headers တွေကို ကိုယ်တိုင် သတ်မှတ်ပါ။ Cookie manager နဲ့ **Headers** tab နှစ်ခုလုံးမှာ cookies တွေ ထည့်နိုင်ပြီး — request မပို့ခင် Postman က cookies တွေကို ပေါင်းစပ်ပေးပါတယ်။

## Scripts တွေနဲ့ cookies ကိုင်တွယ်ခြင်း

Cookies တွေကို ဖန်တီး၊ ရယူ၊ ဖျက်တဲ့ scripts တွေ ရေးနိုင်ပြီး — ဒါက cookies တွေအပေါ် ထိန်းချုပ်မှု ပိုရစေပါတယ်။ Request နဲ့ ဆက်စပ်နေတဲ့ cookies တွေကို access လုပ်ဖို့ `pm.cookies` object ကို သုံးပါ။ Domain တစ်ခုအတွက် cookies တွေကို ဖန်တီး၊ ရယူ၊ ဖျက်ဖို့ `pm.cookies.jar()` methods တွေကို သုံးပါ။ `pm.cookies.jar()` methods တွေနဲ့ domain တစ်ခုချင်းစီရဲ့ cookies တွေကို access လုပ်ဖို့ — အရင်ဆုံး [domains တွေကို allowlist ထဲ ထည့်ထားရပါမယ်](#scripts-တွေထဲမှာ-cookies-တွေကို-access-လုပ်ခြင်း)။

Cookies တွေကို ဖန်တီး၊ ရယူ၊ ဖျက်တဲ့ [scripts တွေ ရေးခြင်း](https://learning.postman.com/docs/tests-and-scripts/write-scripts/postman-sandbox-reference/pm-cookies/) အကြောင်း ပိုလေ့လာပါ။

### Scripts တွေထဲမှာ cookies တွေကို access လုပ်ခြင်း

Domain တစ်ခုကို allowlist ထဲ ထည့်လိုက်တဲ့အခါ — အဲဒီ domain ရဲ့ cookies တွေကို `pm.cookies.jar()` methods တွေ သုံးပြီး scripts တွေထဲမှာ access လုပ်နိုင်ပါတယ်။

Allowlist ထဲကို domain တစ်ခု ထည့်ဖို့ —

1. **Cookies** window ထဲမှာ **Domains allowlist** ကို နှိပ်ပါ။
2. **Add a domain to the allowlist** text box ထဲမှာ ခွင့်ပြုချင်တဲ့ domain ကို ရိုက်ထည့်ပါ။ Domain နာမည် မဟုတ်တဲ့ တခြားအရာ (ဥပမာ protocol) တစ်ခုခု ထည့်လိုက်ရင် — အဲဒီ domain ရဲ့ cookies တွေကို access လုပ်နိုင်မှာ မဟုတ်ပါဘူး။
3. **Add** ကို နှိပ်ပါ။

Allowlist ကနေ domain တစ်ခုကို ဖယ်ရှားဖို့ — domain ဘေးက close icon ကို နှိပ်ပါ။

## Cookies တွေကို sync လုပ်ခြင်း

Postman က browser ဒါမှမဟုတ် client application တစ်ခုအတွက် cookies တွေကို [Postman proxy](https://learning.postman.com/docs/use/capturing-request-data/capture-with-proxy/) ဒါမှမဟုတ် [Postman Interceptor](https://learning.postman.com/docs/use/capturing-request-data/interceptor/) သုံးပြီး capture လုပ်နိုင်ပါတယ်။ ကိုယ် ရွေးထားတဲ့ domains တွေအတွက် — capture လုပ်ထားတဲ့ cookies တွေကို Postman cookie jar နဲ့ စဉ်ဆက်မပြတ် sync လုပ်ပေးပြီး — browser ဒါမှမဟုတ် client application ထဲက authentication sessions တွေကို သုံးပြီး Postman မှာ API calls တွေ လုပ်နိုင်ပါတယ်။

[Postman proxy ဒါမှမဟုတ် Postman Interceptor နဲ့ cookies တွေကို capture လုပ်ခြင်း](https://learning.postman.com/docs/use/capturing-request-data/syncing-cookies/) အကြောင်း ပိုလေ့လာပါ။

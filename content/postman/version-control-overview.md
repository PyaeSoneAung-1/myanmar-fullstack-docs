Postman က ကိုယ့်ရဲ့ collections, environments နဲ့ specifications တွေအတွက် version control ကို ထောက်ပံ့ပေးတာကြောင့် — Postman ထဲမှာ APIs တွေကို အဆင့်ဆင့် တိုးတက်အောင် လုပ်နိုင်ပြီး အတူတကွ ပူးပေါင်း တည်ဆောက်နိုင်ပါတယ်။ Element တစ်ခုကို fork လုပ်နည်း, fork ထဲမှာ updates တွေ လုပ်နည်း နဲ့ ကိုယ့်ရဲ့ အပြောင်းအလဲတွေကို parent element ထဲကို merge လုပ်နည်းတွေကို လေ့လာပါ။

* Element တစ်ခုကို parent element ကနေ fork လုပ်နိုင်ပါတယ်။ Forking က အဲဒီ element အတွက် Editor access မရှိဘဲ — element တစ်ခုထဲကို ပါဝင်ပံ့ပိုးနိုင်စေပါတယ်။ [Postman elements တွေကို fork လုပ်ခြင်း](/docs/postman/forking-elements) အကြောင်း ပိုလေ့လာပါ။

* Fork လုပ်ထားတဲ့ element ထဲမှာ လုပ်ထားတဲ့ ကိုယ့်ရဲ့ အပြောင်းအလဲတွေကို parent element ထဲကို merge လုပ်ဖို့ အဆင်သင့် ဖြစ်တဲ့အခါ — pull request တစ်ခု ဖန်တီးပါ။ [Pull requests တွေ ဖန်တီးခြင်း](/docs/postman/creating-pull-requests) အကြောင်း ပိုလေ့လာပါ။

* အပြောင်းအလဲတွေကို ကြည့်နိုင်, comment လုပ်နိုင်, request ကို approve ဒါမှမဟုတ် decline လုပ်နိုင် ပြီး — fork လုပ်ထားတဲ့ element ကို parent element ထဲကို merge လုပ်နိုင်ပါတယ်။ [Pull requests တွေကို ပြန်သုံးသပ်ခြင်း](/docs/postman/reviewing-pull-requests) အကြောင်း ပိုလေ့လာပါ။

* Team member တစ်ယောက်က pull request တစ်ခုကို ပြင်ဆင်တဲ့အခါ in-app notifications တွေ ရဖို့ — pull request တစ်ခုကို watch လုပ်ပါ။ [Pull requests တွေကို စောင့်ကြည့်ခြင်း](https://learning.postman.com/docs/collaborating-in-postman/using-version-control/watching-pull-requests/) အကြောင်း ပိုလေ့လာပါ။

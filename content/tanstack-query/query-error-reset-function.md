`QueryErrorResetBoundary` ရဲ့ error-reset mechanism နဲ့ ဆက်စပ်တဲ့ function type ဖြစ်ပြီး — query errors တွေကို reset လုပ်တဲ့ function တွေရဲ့ ပုံစံကို သတ်မှတ်ပါတယ်။

```ts
type QueryErrorResetFunction = () => void;
```

## Returns

`void`


`useQueryClient` က ဖတ်တဲ့ context ဖြစ်ပါတယ်။ ဒါကို သတ်မှတ်ဖို့ ပုံမှန် နည်းလမ်းကတော့ `QueryClientProvider` ကို သုံးတာပါ။

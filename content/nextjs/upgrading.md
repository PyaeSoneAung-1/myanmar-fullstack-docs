Next.js ရဲ့ နောက်ဆုံး versions တွေဆီ — version တစ်ခုချင်းစီအတွက် သီးသန့် လမ်းညွှန်တွေ အတိုင်း လိုက်ပြီး ဘယ်လို upgrade လုပ်ရမလဲ လေ့လာနိုင်ပါတယ်:

- [Codemods](https://nextjs.org/docs/app/guides/upgrading/codemods) — Features အသစ်တွေ ထွက်ရှိလာတဲ့အခါ — codemods တွေကို သုံးပြီး သင့် Next.js codebase ကို upgrade လုပ်ပါ။
- [Version 14](https://nextjs.org/docs/app/guides/upgrading/version-14) — သင့် Next.js application ကို Version 13 ကနေ 14 ဆီ upgrade လုပ်ခြင်း။
- [Version 15](https://nextjs.org/docs/app/guides/upgrading/version-15) — သင့် Next.js application ကို Version 14 ကနေ 15 ဆီ upgrade လုပ်ခြင်း။
- [Version 16](/docs/nextjs/upgrading-version-16) — သင့် Next.js application ကို Version 15 ကနေ 16 ဆီ upgrade လုပ်ခြင်း။

Major release line (အဓိက version လိုင်း) တစ်ခုစီရဲ့ နောက်ဆုံး version ကိုပဲ ပံ့ပိုးပေးပါတယ်။

EOL (end-of-life) ဖြစ်နေတဲ့ version တွေက critical security vulnerabilities တွေအတွက်တော့ update တွေ _ရနိုင်ပါတယ်_ — ဒါပေမယ့် Express team က အာမခံချက် မပေးဘဲ၊ တွေ့ရှိရတဲ့ ပြဿနာတွေအတွက် fix တွေ ဖြေရှင်းပေးဖို့ (သို့) release လုပ်ဖို့လည်း မစီစဉ်ထားပါဘူး။

| Major Version (အဓိက ဗားရှင်း) | Minimum Node.js Version (အနည်းဆုံး) | ပံ့ပိုးမှု စတင်သည့်ရက် | ပံ့ပိုးမှု ပြီးဆုံးသည့်ရက် |
| -------------------------------------------------------------- | ------------------------------------- | ------------------------ | -------------------------- |
| [**v5.x**](https://expressjs.com/5x/api)                       | 18                                    | September 2024           | **ဆက်လက် ပံ့ပိုးနေဆဲ**   |
| [**v4.x**](https://expressjs.com/4x/api)                       | 0.10.0                                | April 2014               | **ဆက်လက် ပံ့ပိုးနေဆဲ**   |
| [**v3.x**](https://expressjs.com/3x/api)                       | 0.8.0                                 | October 2012             | July 2015                  |
| [**v2.x**](https://github.com/expressjs/expressjs.com/tree/2x) | 0.4.1                                 | March 2011               | July 2012                  |
| **v1.x**                                                       | 0.2.0                                 | December 2010            | March 2011                 |
| **v0.14.x**                                                    | 0.1.98                                | December 2010            | December 2010              |

## Commercial Support Options

ပံ့ပိုးပေးနေတဲ့ Express version တစ်ခုဆီ update လုပ်ဖို့ မဖြစ်နိုင်ဘူးဆိုရင် — security updates တွေ ရရှိဖို့ အောက်ပါ partner တွေထဲက တစ်ခုကို ဆက်သွယ်ပါ:

- [HeroDevs Never-Ending Support](https://www.herodevs.com/support/express-nes?utm_source=expressjs&utm_medium=link&utm_campaign=express_eol_page)

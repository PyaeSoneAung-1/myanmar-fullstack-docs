## Technical Committee (နည်းပညာ ကော်မတီ)

Express ရဲ့ technical committee က Express ရဲ့ development နဲ့ maintenance၊ Express project နဲ့ သက်ဆိုင်တဲ့ တခြား ကိစ္စရပ်တွေကို ဆွေးနွေးဖို့ နှစ်ပတ်တစ်ကြိမ် (လိုအပ်သလို) online တွေ့ဆုံပါတယ်။ Meeting တစ်ခုချင်းစီကို [expressjs/discussions issue](https://github.com/expressjs/discussions/issues) တစ်ခုအနေနဲ့ ကြေညာလေ့ ရှိပြီး — meeting ကို ဝင်ရောက်ကြည့်ရှုဖို့ (သို့) ကြည့်ရှုဖို့ link ပါဝင်ကာ — observer တွေ အားလုံးအတွက် ဖွင့်ထားပါတယ်။

Meeting တွေကို ရိုက်ကူး သိမ်းဆည်းထားပါတယ် — recordings တွေရဲ့ စာရင်းအတွက် [Express.js YouTube channel](https://www.youtube.com/channel/UCYjxjAeH6TRik9Iwy5nXw7g) ကို ကြည့်ပါ။

## Express ကို module တွေ အများကြီးနဲ့ ဖွဲ့စည်းထားခြင်း

Express ရဲ့ တက်ကြွတဲ့ community က extensions တွေ၊ [middleware module တွေ](https://expressjs.com/en/resources/middleware.html) နဲ့ higher-level frameworks တွေ အမျိုးမျိုး ဖန်တီးထားပါတယ်။

အပြင် — Express community က module တွေကို ဒီ GitHub organization နှစ်ခုအောက်မှာ ထိန်းသိမ်းထားပါတယ်:

- [jshttp](https://github.com/jshttp) — အသုံးဝင်တဲ့ utility function တွေ ပေးတဲ့ module တွေပါ — [Utility modules](/docs/express/utils) ကို ကြည့်ပါ။
- [pillarjs](https://github.com/pillarjs) — Express က အတွင်းပိုင်းမှာ သုံးတဲ့ low-level module တွေပါ။

Community တစ်ခုလုံးမှာ ဘာတွေ ဖြစ်နေလဲ ဆက်လိုက်နိုင်ဖို့ — [ExpressJS StatusBoard](https://expressjs.github.io/statusboard/) ကို ကြည့်ပါ။

## Issues

Bug လို့ ထင်ရတဲ့ အရာတစ်ခုခု တွေ့ခဲ့ရင် (သို့) feature request တစ်ခု တင်ချင်ရင် — [issue queue](https://github.com/expressjs/express/issues) မှာ ticket ဖွင့်ပါ။

## Examples

Repository ထဲမှာ Express application [ဥပမာများ](https://github.com/expressjs/express/tree/master/examples) များစွာ ရှိပြီး — API design နဲ့ authentication ကနေ template engine ပေါင်းစပ်ခြင်းအထိ အကြောင်းအရာ အားလုံးကို ဖုံးအုပ်ထားပါတယ်။

## GitHub Discussions

[GitHub Discussions](https://github.com/expressjs/discussions) ကဏ္ဍက Express ရဲ့ development နဲ့ maintenance အကြောင်း ဆွေးနွေးချက်တွေမှာ ပါဝင်ဖို့၊ အကြံဥာဏ်တွေ မျှဝေဖို့နဲ့ — Express အသုံးပြုမှုနဲ့ ဆိုင်တဲ့ အကြောင်းအရာတွေ ဆွေးနွေးဖို့ အကောင်းဆုံး နေရာတစ်ခုပါ။

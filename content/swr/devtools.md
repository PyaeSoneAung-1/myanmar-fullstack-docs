> SWRDevTools က Vercel ရဲ့ တရားဝင် (official) project မဟုတ်ပါဘူး။

[SWRDevTools](https://swr-devtools.vercel.app/) က SWR အတွက် developer tool တစ်ခုဖြစ်ပြီး — သင့် SWR cache နဲ့ fetcher တွေကို debug လုပ်ဖို့ အထောက်အကူ ပြုပါတယ်။

SWR DevTools ကို extension page တွေကနေ တပ်ဆင်ပြီး — settings ဘာမှ မလိုဘဲ ချက်ချင်း သုံးလို့ရပါတယ်!

- Chrome: https://chrome.google.com/webstore/detail/swr-devtools/liidbicegefhheghhjbomajjaehnjned
- Firefox: https://addons.mozilla.org/en-US/firefox/addon/swr-devtools/

တပ်ဆင်ပြီးတာနဲ့ — browser ရဲ့ developer tools တွေထဲမှာ SWR devtool panel ပေါ်လာပါလိမ့်မယ်။

နောက်ထပ် အချက်အလက်တွေကို [website](https://swr-devtools.vercel.app/) နဲ့ [repository](https://github.com/koba04/swr-devtools) မှာ ကြည့်နိုင်ပါတယ်။

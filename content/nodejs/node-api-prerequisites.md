## C/C++ နဲ့ JavaScript

Node-API ရဲ့ ရည်ရွယ်ချက်က — သင့်မှာ ရှိပြီးသား ဒါမှမဟုတ် အသစ်ရေးထားတဲ့ C/C++ code တွေကို JavaScript ကနေ အသုံးပြုနိုင်အောင် လုပ်ပေးဖို့ပါ။ ဒါကြောင့် JavaScript ရော C/C++ ရော နှစ်မျိုးလုံးကို အနည်းဆုံး အခြေခံအဆင့် (passing familiarity) လောက် နားလည်ထားဖို့ လိုအပ်ပါတယ်။ ဘယ်လောက်အထိ နားလည်ထားဖို့ လိုလဲဆိုတာက — သင့် project ရဲ့ ရှုပ်ထွေးမှု ပေါ်မှာရော၊ JavaScript ဘက်နဲ့ C/C++ ဘက်မှာ သင်ပါဝင်ပတ်သက်နေတဲ့ အတိုင်းအတာပေါ်မှာပါ မူတည်ပါတယ်။

ကိုယ်ပိုင် project တွေအတွက်ဆိုရင် — သင်ပေါင်းစည်း (integrate) လုပ်ဖို့ စီစဉ်ထားတဲ့ C/C++ code ကို နားလည်ထားဖို့ လိုသလို — JavaScript ဘက်ကနေ သင့် project နဲ့ ဘာ objectives တွေ အောင်မြင်ချင်လဲဆိုတာကိုလည်း ရှင်းရှင်းလင်းလင်း သိထားဖို့ လိုအပ်ပါတယ်။

## Command Line Tools

Node-API modules တွေ တည်ဆောက်ရာမှာ သုံးတဲ့ tools အများစုက command line ကနေ run လုပ်ရတာမို့ — command line ကို အနည်းဆုံး အခြေခံအဆင့် ကျွမ်းကျင်ပြီး ယုံကြည်မှု ရှိဖို့က မရှိမဖြစ် လိုအပ်ပါတယ်။ IDE တွေကလည်း [ဒီမှာ](/docs/nodejs/node-api-tools) ဖော်ပြထားသလို အထောက်အကူ ဖြစ်စေနိုင်ပါတယ် — ဒါပေမယ့် ၎င်းတို့ကိုယ်တိုင်ကလည်း command line ပေါ်မှာပဲ မှီခိုနေပါတယ်။

## ဆက်လက်ဖတ်ရှုရန်

ကြိုတင်လိုအပ်ချက်တွေ ပြည့်စုံပြီဆိုရင် — [Node-API Tools များ](/docs/nodejs/node-api-tools) မှာ toolchain တွေ install လုပ်နည်း၊ ပြီးရင် [Node-API Project တစ်ခုရဲ့ ဖွဲ့စည်းပုံ](/docs/nodejs/node-api-project-structure) နဲ့ [ပထမဆုံး Project](/docs/nodejs/node-api-your-first-project) ကို ဆက်ဖတ်နိုင်ပါတယ်။

## 8.8. Geometric Types (ဂျီဩမေတြီ type များ)

- **8.8.1. Points (အမှတ်များ)**
- **8.8.2. Lines (မျဉ်းများ)**
- **8.8.3. Line Segments (မျဉ်း အပိုင်းအစများ)**
- **8.8.4. Boxes (box များ)**
- **8.8.5. Paths (path များ)**
- **8.8.6. Polygons (polygon များ)**
- **8.8.7. Circles (စက်ဝိုင်းများ)**

Geometric data types (ဂျီဩမေတြီ data type များ) တွေက two-dimensional (နှစ်ဘက်မြင်) spatial objects (နေရာဒေသဆိုင်ရာ object များ) တွေကို ကိုယ်စားပြုပါတယ်။ PostgreSQL မှာ ရနိုင်တဲ့ geometric types တွေကို [ဇယား 8.20](/docs/postgresql/datatype-geometric) မှာ ပြထားပါတယ်။

**ဇယား 8.20. Geometric Types (ဂျီဩမေတြီ type များ)**

| နာမည် | သိမ်းဆည်းမှု အရွယ်အစား | ဖော်ပြချက် | ကိုယ်စားပြုပုံ |
| --- | --- | --- | --- |
| `point` | 16 bytes | Plane (မျက်နှာပြင်) ပေါ်ရှိ point (အမှတ်) | (x,y) |
| `line` | 24 bytes | အဆုံးမရှိသော line (မျဉ်း) | {A,B,C} |
| `lseg` | 32 bytes | အဆုံးရှိသော line segment (မျဉ်း အပိုင်းအစ) | [(x1,y1),(x2,y2)] |
| `box` | 32 bytes | စတုဂံပုံ box | (x1,y1),(x2,y2) |
| `path` | 16+16n bytes | ပိတ်ထားသော path (polygon နှင့် ဆင်တူ) | ((x1,y1),...) |
| `path` | 16+16n bytes | ဖွင့်ထားသော path | [(x1,y1),...] |
| `polygon` | 40+16n bytes | Polygon (ဗဟုဂံ) (closed path နှင့် ဆင်တူ) | ((x1,y1),...) |
| `circle` | 24 bytes | Circle (စက်ဝိုင်း) | <(x,y),r> (center point (ဗဟိုအမှတ်) နှင့် radius (အချင်းဝက်)) |

ဒီ type တွေ အားလုံးမှာ — coordinate (ကိုဩဒိနိတ်) တစ်ခုချင်းစီကို `double precision` (`float8`) ဂဏန်းတွေ အနေနဲ့ သိမ်းဆည်းပါတယ်။

Scaling (အချိုးကျ ချဲ့ခြင်း) ၊ translation (နေရာရွှေ့ခြင်း) ၊ rotation (လှည့်ခြင်း) နဲ့ intersection (ဆုံမှတ်) ရှာဖွေခြင်း စတဲ့ geometric operation (ဂျီဩမေတြီ လုပ်ဆောင်ချက်) အမျိုးမျိုးကို လုပ်ဆောင်ဖို့ — function နဲ့ operator အစုအဝေး ကြွယ်ဝစွာ ရရှိနိုင်ပါတယ်။ အဲဒါတွေကို [အပိုင်း 9.11](https://www.postgresql.org/docs/current/functions-geometry.html) မှာ ရှင်းပြထားပါတယ်။

### 8.8.1. Points (အမှတ်များ)

Points တွေက geometric types တွေအတွက် အခြေခံအကျဆုံး two-dimensional (နှစ်ဘက်မြင်) building block (အခြေခံ အဆောက်အအုံ) ဖြစ်ပါတယ်။ `point` type ရဲ့ တန်ဖိုးတွေကို အောက်ပါ syntax နှစ်မျိုးထဲက တစ်မျိုးနဲ့ သတ်မှတ်ပါတယ်:

```sql
( x , y )
  x , y
```

ဒီမှာ `x` နဲ့ `y` တွေက သက်ဆိုင်ရာ coordinate (ကိုဩဒိနိတ်) တွေ ဖြစ်ပြီး — floating-point ဂဏန်းတွေ အနေနဲ့ ရှိပါတယ်။

Points တွေကို output (ထုတ်ပြခြင်း) လုပ်တဲ့အခါမှာတော့ ပထမ syntax ကို သုံးပါတယ်။

### 8.8.2. Lines (မျဉ်းများ)

Lines တွေကို linear equation (မျဉ်းဖြောင့် ညီမျှခြင်း) `A`x + `B`y + `C` = 0 နဲ့ ကိုယ်စားပြုပါတယ် — ဒီမှာ `A` နဲ့ `B` က နှစ်ခုလုံး သုည မဖြစ်ရပါဘူး။ `line` type ရဲ့ တန်ဖိုးတွေကို အောက်ပါ ပုံစံနဲ့ input (ထည့်သွင်း) လုပ်ပြီး output (ထုတ်ပြ) လုပ်ပါတယ်:

```sql
{ A, B, C }
```

တနည်းအားဖြင့် — input (ထည့်သွင်း) လုပ်ဖို့အတွက် အောက်ပါ ပုံစံတွေထဲက ဘယ်ဟာကိုမဆို သုံးနိုင်ပါတယ်:

```sql
[ ( x1 , y1 ) , ( x2 , y2 ) ]
( ( x1 , y1 ) , ( x2 , y2 ) )
  ( x1 , y1 ) , ( x2 , y2 )
    x1 , y1   ,   x2 , y2
```

ဒီမှာ `(x1,y1)` နဲ့ `(x2,y2)` တွေက line (မျဉ်း) ပေါ်မှာ ရှိတဲ့ မတူညီတဲ့ point (အမှတ်) နှစ်ခု ဖြစ်ပါတယ်။

### 8.8.3. Line Segments (မျဉ်း အပိုင်းအစများ)

Line segments (မျဉ်း အပိုင်းအစများ) တွေကို segment ရဲ့ အစွန်းနှစ်ဖက် (endpoint) ဖြစ်တဲ့ point (အမှတ်) အတွဲတွေနဲ့ ကိုယ်စားပြုပါတယ်။ `lseg` type ရဲ့ တန်ဖိုးတွေကို အောက်ပါ syntax တွေထဲက ဘယ်ဟာနဲ့မဆို သတ်မှတ်နိုင်ပါတယ်:

```sql
[ ( x1 , y1 ) , ( x2 , y2 ) ]
( ( x1 , y1 ) , ( x2 , y2 ) )
  ( x1 , y1 ) , ( x2 , y2 )
    x1 , y1   ,   x2 , y2
```

ဒီမှာ `(x1,y1)` နဲ့ `(x2,y2)` တွေက line segment (မျဉ်း အပိုင်းအစ) ရဲ့ အစွန်းအမှတ် (end point) တွေ ဖြစ်ပါတယ်။

Line segments တွေကို output (ထုတ်ပြ) လုပ်တဲ့အခါမှာတော့ ပထမ syntax ကို သုံးပါတယ်။

### 8.8.4. Boxes (box များ)

Boxes (box များ) တွေကို box ရဲ့ ဆန့်ကျင်ဘက် ထောင့် (opposite corner) အတွဲ ဖြစ်တဲ့ point (အမှတ်) အတွဲတွေနဲ့ ကိုယ်စားပြုပါတယ်။ `box` type ရဲ့ တန်ဖိုးတွေကို အောက်ပါ syntax တွေထဲက ဘယ်ဟာနဲ့မဆို သတ်မှတ်နိုင်ပါတယ်:

```sql
( ( x1 , y1 ) , ( x2 , y2 ) )
  ( x1 , y1 ) , ( x2 , y2 )
    x1 , y1   ,   x2 , y2
```

ဒီမှာ `(x1,y1)` နဲ့ `(x2,y2)` တွေက box ရဲ့ ဆန့်ကျင်ဘက် ထောင့် ဘယ်အတွဲမဆို ဖြစ်နိုင်ပါတယ်။

Boxes တွေကို output (ထုတ်ပြ) လုပ်တဲ့အခါမှာတော့ ဒုတိယ syntax ကို သုံးပါတယ်။

Input (ထည့်သွင်း) လုပ်တဲ့အခါ ဆန့်ကျင်ဘက် ထောင့် ဘယ်အတွဲကိုမဆို ပေးလို့ ရပါတယ် — ဒါပေမယ့် တန်ဖိုးတွေကို upper right (အပေါ်ညာဘက်) နဲ့ lower left (အောက်ဘယ်ဘက်) ထောင့်တွေ ဖြစ်အောင် — အဲဒီ အစီအစဉ်အတိုင်း — လိုအပ်သလို ပြန်စီပြီး သိမ်းဆည်းပါတယ်။

### 8.8.5. Paths (path များ)

Paths (path များ) တွေကို ဆက်စပ်နေတဲ့ point (အမှတ်) တွေရဲ့ စာရင်းတွေနဲ့ ကိုယ်စားပြုပါတယ်။ Path တွေဟာ *open* (ဖွင့်ထားသော) ဖြစ်နိုင်ပါတယ် — အဲဒီအခါ စာရင်းထဲက ပထမဆုံးနဲ့ နောက်ဆုံး point တွေကို ဆက်စပ်မှု မရှိဘူးလို့ သတ်မှတ်ပြီး — ဒါမှမဟုတ် *closed* (ပိတ်ထားသော) ဖြစ်နိုင်ပါတယ် — အဲဒီအခါ ပထမဆုံးနဲ့ နောက်ဆုံး point တွေကို ဆက်စပ်နေတယ်လို့ သတ်မှတ်ပါတယ်။

`path` type ရဲ့ တန်ဖိုးတွေကို အောက်ပါ syntax တွေထဲက ဘယ်ဟာနဲ့မဆို သတ်မှတ်နိုင်ပါတယ်:

```sql
[ ( x1 , y1 ) , ... , ( xn , yn ) ]
( ( x1 , y1 ) , ... , ( xn , yn ) )
  ( x1 , y1 ) , ... , ( xn , yn )
  ( x1 , y1   , ... ,   xn , yn )
    x1 , y1   , ... ,   xn , yn
```

ဒီမှာ point (အမှတ်) တွေက path ကို ဖွဲ့စည်းထားတဲ့ line segments (မျဉ်း အပိုင်းအစများ) တွေရဲ့ အစွန်းအမှတ် (end point) တွေ ဖြစ်ပါတယ်။ Square brackets (`[]`) တွေက open path (ဖွင့်ထားသော path) ကို ညွှန်ပြပြီး — parentheses (`()`) တွေကတော့ closed path (ပိတ်ထားသော path) ကို ညွှန်ပြပါတယ်။ တတိယကနေ ပဉ္စမ syntax တွေထဲမှာလိုပဲ အပြင်ဘက်ဆုံး parentheses တွေကို ချန်လိုက်တဲ့အခါ — closed path (ပိတ်ထားသော path) လို့ ယူဆပါတယ်။

Paths တွေကို output (ထုတ်ပြ) လုပ်တဲ့အခါမှာတော့ — သင့်လျော်သလို — ပထမ သို့မဟုတ် ဒုတိယ syntax ကို သုံးပါတယ်။

### 8.8.6. Polygons (polygon များ)

Polygons (polygon များ) တွေကို point (အမှတ်) တွေရဲ့ စာရင်းနဲ့ ကိုယ်စားပြုပါတယ် (ဒီ point တွေက polygon ရဲ့ vertices (ထောင့်စွန်းများ) ဖြစ်ပါတယ်)။ Polygons တွေက closed paths (ပိတ်ထားသော path များ) တွေနဲ့ အလွန် ဆင်တူပါတယ်; အဓိက semantic (အဓိပ္ပာယ်) ကွာခြားချက်ကတော့ — polygon ကို ၎င်းအတွင်းမှာရှိတဲ့ ဧရိယာ (area) အပါအဝင် ဖြစ်တယ်လို့ သတ်မှတ်ပြီး — path ကတော့ အဲဒီလို မပါဝင်ဘူးလို့ သတ်မှတ်တာ ဖြစ်ပါတယ်။

Polygons နဲ့ paths တွေကြားမှာ အရေးကြီးတဲ့ implementation (အကောင်အထည်ဖော်မှု) ကွာခြားချက် တစ်ခုက — polygon တစ်ခုရဲ့ သိမ်းဆည်းထားသော representation (ကိုယ်စားပြုပုံ) မှာ ၎င်းရဲ့ အသေးဆုံး bounding box (ဝန်းရံအကွက်) ပါဝင်နေတာ ဖြစ်ပါတယ်။ ဒါက search (ရှာဖွေမှု) လုပ်ဆောင်ချက် တချို့ကို မြန်ဆန်စေပါတယ် — ဒါပေမယ့် polygon အသစ်တွေ တည်ဆောက်တဲ့အခါမှာတော့ bounding box တွက်ချက်မှုက overhead (ထပ်ဆောင်း တွက်ချက်မှု) ကို ပေါင်းထည့်ပါတယ်။

`polygon` type ရဲ့ တန်ဖိုးတွေကို အောက်ပါ syntax တွေထဲက ဘယ်ဟာနဲ့မဆို သတ်မှတ်နိုင်ပါတယ်:

```sql
( ( x1 , y1 ) , ... , ( xn , yn ) )
  ( x1 , y1 ) , ... , ( xn , yn )
  ( x1 , y1   , ... ,   xn , yn )
    x1 , y1   , ... ,   xn , yn
```

ဒီမှာ point (အမှတ်) တွေက polygon ရဲ့ နယ်နိမိတ် (boundary) ကို ဖွဲ့စည်းထားတဲ့ line segments (မျဉ်း အပိုင်းအစများ) တွေရဲ့ အစွန်းအမှတ် (end point) တွေ ဖြစ်ပါတယ်။

Polygons တွေကို output (ထုတ်ပြ) လုပ်တဲ့အခါမှာတော့ ပထမ syntax ကို သုံးပါတယ်။

### 8.8.7. Circles (စက်ဝိုင်းများ)

Circles (စက်ဝိုင်းများ) တွေကို center point (ဗဟိုအမှတ်) နဲ့ radius (အချင်းဝက်) နဲ့ ကိုယ်စားပြုပါတယ်။ `circle` type ရဲ့ တန်ဖိုးတွေကို အောက်ပါ syntax တွေထဲက ဘယ်ဟာနဲ့မဆို သတ်မှတ်နိုင်ပါတယ်:

```sql
< ( x , y ) , r >
( ( x , y ) , r )
  ( x , y ) , r
    x , y   , r
```

ဒီမှာ `(x,y)` က center point (ဗဟိုအမှတ်) ဖြစ်ပြီး — `r` က circle (စက်ဝိုင်း) ရဲ့ radius (အချင်းဝက်) ဖြစ်ပါတယ်။

Circles တွေကို output (ထုတ်ပြ) လုပ်တဲ့အခါမှာတော့ ပထမ syntax ကို သုံးပါတယ်။

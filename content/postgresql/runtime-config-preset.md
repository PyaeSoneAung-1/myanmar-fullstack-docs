## 19.15. Preset Options (ကြိုတင် သတ်မှတ်ထားသော ရွေးချယ်စရာများ)

အောက်ပါ “parameters” (ပါရာမီတာများ) တွေက read-only (ဖတ်ရှုရုံသာ) ဖြစ်ပါတယ်။ ဒါကြောင့် — သူတို့ကို နမူနာ `postgresql.conf` ဖိုင်ထဲမှာ ထည့်သွင်း မထားပါဘူး။ ဒီ ရွေးချယ်စရာ (options) တွေက — အချို့ applications တွေ အထူးသဖြင့် administrative front-ends (စီမံခန့်ခွဲရေး front-end များ) အတွက် စိတ်ဝင်စားဖွယ် ဖြစ်နိုင်တဲ့ — PostgreSQL ရဲ့ အပြုအမူ ရှုထောင့် အမျိုးမျိုးကို ဖော်ပြပေးပါတယ်။ သူတို့ အများစုက — PostgreSQL ကို compile လုပ်တဲ့အခါ ဒါမှမဟုတ် install လုပ်တဲ့အခါ ဆုံးဖြတ် သတ်မှတ်ပါတယ်။

- **block_size (integer)** — disk block (disk ဘလောက်) တစ်ခုရဲ့ အရွယ်အစားကို ဖော်ပြပါတယ်။ ဒါကို server ကို build လုပ်တဲ့အခါ `BLCKSZ` ရဲ့ တန်ဖိုးက ဆုံးဖြတ် သတ်မှတ်ပါတယ်။ Default တန်ဖိုးက 8192 bytes ဖြစ်ပါတယ်။ အချို့ configuration variable တွေ (ဥပမာ [shared_buffers](/docs/postgresql/runtime-config-resource)) ရဲ့ အဓိပ္ပာယ်က `block_size` ရဲ့ လွှမ်းမိုးမှုကို ခံရပါတယ်။ အချက်အလက်အတွက် [အပိုင်း 19.4](/docs/postgresql/runtime-config-resource) ကို ကြည့်ပါ။
- **data_checksums (boolean)** — ဒီ cluster အတွက် data checksums တွေ enable ဖြစ်ထားသလား ဆိုတာကို ဖော်ပြပါတယ်။ နောက်ထပ် အချက်အလက်အတွက် [-k](https://www.postgresql.org/docs/current/app-initdb.html#APP-INITDB-DATA-CHECKSUMS) ကို ကြည့်ပါ။
- **data_directory_mode (integer)** — Unix system တွေမှာ — ဒီ parameter က — server စတင်တဲ့အခါ data directory ([data_directory](/docs/postgresql/runtime-config-file-locations) နဲ့ သတ်မှတ်ထားတဲ့) မှာ ရှိခဲ့တဲ့ permission တွေကို ဖော်ပြပါတယ်။ (Microsoft Windows မှာတော့ ဒီ parameter က အမြဲတမ်း 0700 ကို ပြပါလိမ့်မယ်။) နောက်ထပ် အချက်အလက်အတွက် [initdb ရဲ့ -g option](https://www.postgresql.org/docs/current/app-initdb.html#APP-INITDB-ALLOW-GROUP-ACCESS) ကို ကြည့်ပါ။
- **debug_assertions (boolean)** — PostgreSQL ကို assertions (အတည်ပြု စစ်ဆေးချက်များ) enable ဖြစ်ထားပြီး build လုပ်ထားသလား ဆိုတာကို ဖော်ပြပါတယ်။ PostgreSQL ကို build လုပ်တဲ့အခါ `USE_ASSERT_CHECKING` macro ကို define လုပ်ထားရင် အဲဒီလို ဖြစ်ပါတယ် (ဥပမာ — `--enable-cassert` ဆိုတဲ့ configure option နဲ့ လုပ်ဆောင်နိုင်ပါတယ်)။ Default အားဖြင့် — PostgreSQL ကို assertions မပါဘဲ build လုပ်ထားပါတယ်။
- **huge_pages_status (enum)** — လက်ရှိ instance မှာ huge pages (ကြီးမားသော page များ) တွေရဲ့ အခြေအနေကို ဖော်ပြပါတယ် — on, off, ဒါမှမဟုတ် unknown (`postgres -C` နဲ့ ပြသရင်) ဆိုပြီးပါ။ `huge_pages=try` အောက်မှာ huge pages တွေ ခွဲဝေချထားမှု (allocation) အောင်မြင်ခဲ့သလား ဆိုတာ ဆုံးဖြတ်ဖို့ ဒီ parameter က အသုံးဝင်ပါတယ်။ နောက်ထပ် အချက်အလက်အတွက် [huge_pages](/docs/postgresql/runtime-config-resource) ကို ကြည့်ပါ။
- **integer_datetimes (boolean)** — PostgreSQL ကို 64-bit integer dates and times (ရက်စွဲနှင့် အချိန်များ) အတွက် ပံ့ပိုးမှုနဲ့အတူ build လုပ်ထားသလား ဆိုတာကို ဖော်ပြပါတယ်။ PostgreSQL 10 ကတည်းက — ဒါက အမြဲတမ်း on ဖြစ်ပါတယ်။
- **in_hot_standby (boolean)** — server က လက်ရှိ hot standby mode မှာ ရှိသလား ဆိုတာကို ဖော်ပြပါတယ်။ ဒါက on ဖြစ်နေတဲ့အခါ — transaction အားလုံးကို read-only ဖြစ်အောင် အတင်းအကျပ် သတ်မှတ်ပါတယ်။ session တစ်ခုအတွင်းမှာ — server ကို primary (ပင်မ) အဖြစ် promote (ရာထူးမြှင့်) လုပ်တဲ့အခါမှသာ ဒါက ပြောင်းလဲနိုင်ပါတယ်။ နောက်ထပ် အချက်အလက်အတွက် [အပိုင်း 26.4](/docs/postgresql/hot-standby) ကို ကြည့်ပါ။
- **max_function_args (integer)** — function argument အများဆုံး အရေအတွက်ကို ဖော်ပြပါတယ်။ ဒါကို server ကို build လုပ်တဲ့အခါ `FUNC_MAX_ARGS` ရဲ့ တန်ဖိုးက ဆုံးဖြတ် သတ်မှတ်ပါတယ်။ Default တန်ဖိုးက argument 100 ခု ဖြစ်ပါတယ်။
- **max_identifier_length (integer)** — identifier (အမည် အမှတ်အသား) အရှည် အများဆုံးကို ဖော်ပြပါတယ်။ ဒါကို server ကို build လုပ်တဲ့အခါ `NAMEDATALEN` ရဲ့ တန်ဖိုးထက် တစ်ခု လျော့တဲ့ တန်ဖိုးအဖြစ် ဆုံးဖြတ် သတ်မှတ်ပါတယ်။ `NAMEDATALEN` ရဲ့ default တန်ဖိုးက 64 ဖြစ်ပါတယ်; ဒါကြောင့် default `max_identifier_length` က 63 bytes ဖြစ်ပြီး — multibyte encoding တွေ သုံးတဲ့အခါ — စာလုံး 63 လုံးထက် နည်းနိုင်ပါတယ်။
- **max_index_keys (integer)** — index key အများဆုံး အရေအတွက်ကို ဖော်ပြပါတယ်။ ဒါကို server ကို build လုပ်တဲ့အခါ `INDEX_MAX_KEYS` ရဲ့ တန်ဖိုးက ဆုံးဖြတ် သတ်မှတ်ပါတယ်။ Default တန်ဖိုးက key 32 ခု ဖြစ်ပါတယ်။
- **num_os_semaphores (integer)** — ခွင့်ပြုထားတဲ့ connection အရေအတွက် ([max_connections](/docs/postgresql/runtime-config-connection)), ခွင့်ပြုထားတဲ့ autovacuum worker process များ ([autovacuum_max_workers](/docs/postgresql/runtime-config-vacuum)), ခွင့်ပြုထားတဲ့ WAL sender process များ ([max_wal_senders](/docs/postgresql/runtime-config-replication)), ခွင့်ပြုထားတဲ့ background process များ ([max_worker_processes](/docs/postgresql/runtime-config-resource)) စတာတွေကို အခြေခံပြီး — server အတွက် လိုအပ်တဲ့ semaphore (ဆီမာဖိုး) အရေအတွက်ကို ဖော်ပြပါတယ်။
- **segment_size (integer)** — file segment တစ်ခုအတွင်း သိမ်းဆည်းနိုင်တဲ့ block (page) အရေအတွက်ကို ဖော်ပြပါတယ်။ ဒါကို server ကို build လုပ်တဲ့အခါ `RELSEG_SIZE` ရဲ့ တန်ဖိုးက ဆုံးဖြတ် သတ်မှတ်ပါတယ်။ segment ဖိုင်တစ်ခုရဲ့ အများဆုံး အရွယ်အစားက — bytes နဲ့ဆိုရင် — `segment_size` ကို `block_size` နဲ့ မြှောက်တာနဲ့ ညီပါတယ်; default အားဖြင့် ဒါက 1GB ဖြစ်ပါတယ်။
- **server_encoding (string)** — database encoding (စာလုံး အစု — character set) ကို ဖော်ပြပါတယ်။ ဒါကို database ဖန်တီးတဲ့အခါ ဆုံးဖြတ် သတ်မှတ်ပါတယ်။ သာမန်အားဖြင့် — client များက [client_encoding](/docs/postgresql/runtime-config-client) ရဲ့ တန်ဖိုးကိုပဲ ဂရုစိုက်ရန် လိုပါတယ်။
- **server_version (string)** — server ရဲ့ version number (ဗားရှင်း နံပါတ်) ကို ဖော်ပြပါတယ်။ ဒါကို server ကို build လုပ်တဲ့အခါ `PG_VERSION` ရဲ့ တန်ဖိုးက ဆုံးဖြတ် သတ်မှတ်ပါတယ်။
- **server_version_num (integer)** — server ရဲ့ version number ကို integer တစ်ခုအဖြစ် ဖော်ပြပါတယ်။ ဒါကို server ကို build လုပ်တဲ့အခါ `PG_VERSION_NUM` ရဲ့ တန်ဖိုးက ဆုံးဖြတ် သတ်မှတ်ပါတယ်။
- **shared_memory_size (integer)** — အဓိက shared memory (မျှဝေ မှတ်ဉာဏ်) ဧရိယာရဲ့ အရွယ်အစားကို — အနီးဆုံး megabyte အထိ အပေါ်ကို လှမ်း (round up) ပြီး — ဖော်ပြပါတယ်။
- **shared_memory_size_in_huge_pages (integer)** — သတ်မှတ်ထားတဲ့ [huge_page_size](/docs/postgresql/runtime-config-resource) ကို အခြေခံပြီး — အဓိက shared memory ဧရိယာအတွက် လိုအပ်တဲ့ huge page အရေအတွက်ကို ဖော်ပြပါတယ်။ huge pages တွေကို ပံ့ပိုးမထားရင် — ဒါက -1 ဖြစ်ပါလိမ့်မယ်။
ဒီ setting ကို Linux မှာသာ ပံ့ပိုးပါတယ်။ အခြား platform တွေမှာ ဒါကို အမြဲတမ်း -1 လို့ သတ်မှတ်ထားပါတယ်။ Linux မှာ huge pages တွေ အသုံးပြုခြင်းအကြောင်း အသေးစိတ်အတွက် [အပိုင်း 18.4.5](/docs/postgresql/kernel-resources) ကို ကြည့်ပါ။
- **ssl_library (string)** — ဒီ PostgreSQL server ကို build လုပ်တဲ့အခါ အသုံးပြုခဲ့တဲ့ SSL library (SSL စာကြည့်တိုက်) ရဲ့ အမည်ကို ဖော်ပြပါတယ် (ဒီ instance မှာ SSL ကို လက်ရှိ configure မလုပ်ထားတာ ဒါမှမဟုတ် အသုံးမပြုနေတာ ဖြစ်နေရင်တောင်) — ဥပမာ OpenSSL၊ ဒါမှမဟုတ် မရှိရင် empty string (စာလုံး အလွတ်) တစ်ခု ဖြစ်ပါတယ်။
- **wal_block_size (integer)** — WAL disk block တစ်ခုရဲ့ အရွယ်အစားကို ဖော်ပြပါတယ်။ ဒါကို server ကို build လုပ်တဲ့အခါ `XLOG_BLCKSZ` ရဲ့ တန်ဖိုးက ဆုံးဖြတ် သတ်မှတ်ပါတယ်။ Default တန်ဖိုးက 8192 bytes ဖြစ်ပါတယ်။
- **wal_segment_size (integer)** — write ahead log segment (WAL segment) တွေရဲ့ အရွယ်အစားကို ဖော်ပြပါတယ်။ Default တန်ဖိုးက 16MB ဖြစ်ပါတယ်။ နောက်ထပ် အချက်အလက်အတွက် [အပိုင်း 28.5](/docs/postgresql/wal-configuration) ကို ကြည့်ပါ။

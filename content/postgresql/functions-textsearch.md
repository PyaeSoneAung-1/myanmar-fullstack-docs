## 9.13. Text Search Functions and Operators (text search လုပ်ဆောင်ချက်များနှင့် operator များ)

ဇယား 9.42၊ ဇယား 9.43 နဲ့ ဇယား 9.44 တွေက full text searching (full text search — စာသား အပြည့်အစုံ ရှာဖွေမှု) အတွက် ပံ့ပိုးပေးထားတဲ့ functions နဲ့ operators တွေရဲ့ အကျဉ်းချုပ်ကို ဖော်ပြထားပါတယ်။ PostgreSQL ရဲ့ text search facility (စာသား ရှာဖွေမှု စနစ်) အကြောင်း အသေးစိတ် ရှင်းလင်းချက်အတွက် [အခန်း 12](https://www.postgresql.org/docs/current/textsearch.html) ကို ကြည့်ပါ။

**ဇယား 9.42. Text Search Operators (text search operator များ)**

| Operator | ဖော်ပြချက် | ဥပမာ |
| --- | --- | --- |
| tsvector @@ tsquery → boolean tsquery @@ tsvector → boolean | tsvector က tsquery နဲ့ ကိုက်ညီမှု ရှိမရှိ စစ်ဆေးပါတယ် (argument နှစ်ခုလုံးကို ဘယ်လို အစဉ်လိုက်ပဲ ပေးပေး ရပါတယ်)။ | to_tsvector('fat cats ate rats') @@ to_tsquery('cat & rat') → t |
| text @@ tsquery → boolean | text string က — to_tsvector() ကို သွယ်ဝိုက်၍ (implicitly) ခေါ်ယူပြီးမှ — tsquery နဲ့ ကိုက်ညီမှု ရှိမရှိ စစ်ဆေးပါတယ်။ | 'fat cats ate rats' @@ to_tsquery('cat & rat') → t |
| tsvector \|\| tsvector → tsvector | tsvector နှစ်ခုကို ဆက်စပ် ပေါင်းစည်းပါတယ် (concatenate)။ Input နှစ်ခုလုံးမှာ lexeme positions (စကားလုံး နေရာကိန်း အမှတ်များ) ပါဝင်နေရင် — ဒုတိယ input ရဲ့ positions တွေကို လိုက်လျောညီထွေ ချိန်ညှိ (adjust) ပေးပါတယ်။ | 'a:1 b:2'::tsvector \|\| 'c:1 d:2 b:3'::tsvector → 'a':1 'b':2,5 'c':3 'd':4 |
| tsquery && tsquery → tsquery | tsquery နှစ်ခုကို AND (နှင့်) ချိတ်ဆက်ပြီး — input query နှစ်ခုလုံးနဲ့ ကိုက်ညီတဲ့ documents တွေကို match လုပ်မယ့် query တစ်ခုကို ထုတ်လုပ်ပေးပါတယ်။ | 'fat \| rat'::tsquery && 'cat'::tsquery → ( 'fat' \| 'rat' ) & 'cat' |
| tsquery \|\| tsquery → tsquery | tsquery နှစ်ခုကို OR (သို့) ချိတ်ဆက်ပြီး — input query တစ်ခုခုနဲ့ ကိုက်ညီတဲ့ documents တွေကို match လုပ်မယ့် query တစ်ခုကို ထုတ်လုပ်ပေးပါတယ်။ | 'fat \| rat'::tsquery \|\| 'cat'::tsquery → 'fat' \| 'rat' \| 'cat' |
| !! tsquery → tsquery | tsquery တစ်ခုကို ငြင်းပယ် (negate) လုပ်ပြီး — input query နဲ့ မကိုက်ညီတဲ့ documents တွေကို match လုပ်မယ့် query တစ်ခုကို ထုတ်လုပ်ပေးပါတယ်။ | !! 'cat'::tsquery → !'cat' |
| tsquery <-> tsquery → tsquery | Phrase query (စကားစု query) တစ်ခုကို တည်ဆောက်ပေးပြီး — input query နှစ်ခုရဲ့ match တွေက ဆက်တိုက် (successive) lexemes တွေမှာ ဖြစ်မှသာ ကိုက်ညီပါတယ်။ | to_tsquery('fat') <-> to_tsquery('rat') → 'fat' <-> 'rat' |
| tsquery @> tsquery → boolean | ပထမ tsquery ထဲမှာ ဒုတိယ tsquery ပါဝင်နေသလား? (ဒါက query တစ်ခုထဲမှာ ပါဝင်တဲ့ lexemes တွေ အားလုံး နောက် query တစ်ခုထဲမှာ ပါဝင်မဝင် ဆိုတာကိုပဲ ထည့်စဉ်းစားပြီး — ပေါင်းစပ်ထားတဲ့ (combining) operators တွေကိုတော့ လျစ်လျူရှုပါတယ်။) | 'cat'::tsquery @> 'cat & rat'::tsquery → f |
| tsquery <@ tsquery → boolean | ပထမ tsquery က ဒုတိယ tsquery ထဲမှာ ပါဝင်နေသလား? (ဒါက query တစ်ခုထဲမှာ ပါဝင်တဲ့ lexemes တွေ အားလုံး နောက် query တစ်ခုထဲမှာ ပါဝင်မဝင် ဆိုတာကိုပဲ ထည့်စဉ်းစားပြီး — ပေါင်းစပ်ထားတဲ့ operators တွေကိုတော့ လျစ်လျူရှုပါတယ်။) | 'cat'::tsquery <@ 'cat & rat'::tsquery → t 'cat'::tsquery <@ '!cat & rat'::tsquery → t |

ဒီအထူးပြု (specialized) operators တွေအပြင် — [ဇယား 9.1](/docs/postgresql/functions-comparison) မှာ ပြထားတဲ့ သာမန် comparison operators တွေကိုလည်း `tsvector` နဲ့ `tsquery` types တွေအတွက် သုံးလို့ ရပါတယ်။ ဒါတွေက text searching အတွက်တော့ သိပ် အသုံးမဝင်ပေမယ့် — ဥပမာ — ဒီ types တွေရဲ့ columns တွေပေါ်မှာ unique indexes (ထူးခြားမှု ရှိစေသော index များ) တည်ဆောက်ဖို့အတွက်တော့ ခွင့်ပြုပေးပါတယ်။

**ဇယား 9.43. Text Search Functions (text search function များ)**

| Function | ဖော်ပြချက် | ဥပမာ |
| --- | --- | --- |
| array_to_tsvector ( text[] ) → tsvector | text strings တွေရဲ့ array တစ်ခုကို tsvector အဖြစ် ပြောင်းပေးပါတယ်။ ပေးထားတဲ့ strings တွေကို lexemes တွေအနေနဲ့ — နောက်ထပ် process လုပ်ခြင်း မရှိဘဲ — မူရင်းအတိုင်း (as-is) သုံးပါတယ်။ Array elements တွေက empty strings ဒါမှမဟုတ် NULL ဖြစ်လို့ မရပါဘူး။ | array_to_tsvector('{fat,cat,rat}'::text[]) → 'cat' 'fat' 'rat' |
| get_current_ts_config ( ) → regconfig | လက်ရှိ ပုံသေ text search configuration ရဲ့ OID ကို ပြန်ပေးပါတယ် (default_text_search_config က သတ်မှတ်ထားတဲ့အတိုင်း)။ | get_current_ts_config() → english |
| length ( tsvector ) → integer | tsvector ထဲက lexemes အရေအတွက်ကို ပြန်ပေးပါတယ်။ | length('fat:2,4 cat:3 rat:5A'::tsvector) → 3 |
| numnode ( tsquery ) → integer | tsquery ထဲက lexemes နဲ့ operators တွေ ပေါင်းထားတဲ့ အရေအတွက်ကို ပြန်ပေးပါတယ်။ | numnode('(fat & rat) \| cat'::tsquery) → 5 |
| plainto_tsquery ( [ config regconfig, ] query text ) → tsquery | Text ကို — သတ်မှတ်ထားတဲ့ (သို့) ပုံသေ configuration အတိုင်း စကားလုံးတွေကို normalize လုပ်ပြီး — tsquery အဖြစ် ပြောင်းပေးပါတယ်။ String ထဲက punctuation (ပုဒ်ဖြတ် သင်္ကေတ) တွေကို လျစ်လျူရှုပါတယ် (သူတို့က query operators တွေကို ဆုံးဖြတ်ပေးတာ မဟုတ်ပါဘူး)။ ရလာတဲ့ query က — text ထဲက stop words (ရှာဖွေမှုမှာ အသုံးမဝင်လောက်အောင် မကြာခဏ ပေါ်နေသော စကားလုံးများ) မဟုတ်တဲ့ စကားလုံး (non-stopword) တွေ အားလုံး ပါဝင်တဲ့ documents တွေနဲ့ ကိုက်ညီပါတယ်။ | plainto_tsquery('english', 'The Fat Rats') → 'fat' & 'rat' |
| phraseto_tsquery ( [ config regconfig, ] query text ) → tsquery | Text ကို — သတ်မှတ်ထားတဲ့ (သို့) ပုံသေ configuration အတိုင်း စကားလုံးတွေကို normalize လုပ်ပြီး — tsquery အဖြစ် ပြောင်းပေးပါတယ်။ String ထဲက punctuation တွေကို လျစ်လျူရှုပါတယ် (သူတို့က query operators တွေကို ဆုံးဖြတ်ပေးတာ မဟုတ်ပါဘူး)။ ရလာတဲ့ query က — text ထဲက non-stopwords တွေ အားလုံး ပါဝင်တဲ့ phrases (စကားစုများ) တွေနဲ့ ကိုက်ညီပါတယ်။ | phraseto_tsquery('english', 'The Fat Rats') → 'fat' <-> 'rat' phraseto_tsquery('english', 'The Cat and Rats') → 'cat' <2> 'rat' |
| websearch_to_tsquery ( [ config regconfig, ] query text ) → tsquery | Text ကို — သတ်မှတ်ထားတဲ့ (သို့) ပုံသေ configuration အတိုင်း စကားလုံးတွေကို normalize လုပ်ပြီး — tsquery အဖြစ် ပြောင်းပေးပါတယ်။ Quote (ကိုးကားအမှတ်) တွေနဲ့ ဝန်းရံထားတဲ့ စကားလုံး အစီအစဉ်တွေကို phrase tests (စကားစု စမ်းသပ်မှုများ) အဖြစ် ပြောင်းပါတယ်။ “or” ဆိုတဲ့ စကားလုံးကို OR operator တစ်ခု ထုတ်လုပ်ပေးတဲ့အနေနဲ့ နားလည်ပြီး — dash (မျဉ်းတို) တစ်ခုကတော့ NOT operator တစ်ခုကို ထုတ်လုပ်ပေးပါတယ်; ကျန်တဲ့ punctuation တွေကိုတော့ လျစ်လျူရှုပါတယ်။ ဒါက web search tools (ဝဘ် ရှာဖွေရေး ကိရိယာများ) တချို့ရဲ့ အပြုအမူနဲ့ အနီးစပ်ဆုံး ဆင်တူပါတယ်။ | websearch_to_tsquery('english', '"fat rat" or cat dog') → 'fat' <-> 'rat' \| 'cat' & 'dog' |
| querytree ( tsquery ) → text | tsquery တစ်ခုရဲ့ index လုပ်လို့ရတဲ့ (indexable) အပိုင်းရဲ့ ကိုယ်စားပြုမှု (representation) တစ်ခုကို ထုတ်လုပ်ပေးပါတယ်။ Empty ဖြစ်နေတဲ့ ဒါမှမဟုတ် T သက်သက်သာ ဖြစ်နေတဲ့ ရလဒ်က — index လုပ်လို့ မရတဲ့ (non-indexable) query တစ်ခုကို ညွှန်ပြပါတယ်။ | querytree('foo & ! bar'::tsquery) → 'foo' |
| setweight ( vector tsvector, weight "char" ) → tsvector | သတ်မှတ်ထားတဲ့ weight (အလေးချိန် အဆင့်) ကို vector ရဲ့ element တစ်ခုချင်းစီဆီမှာ သတ်မှတ်ပေးပါတယ် (assign)။ | setweight('fat:2,4 cat:3 rat:5B'::tsvector, 'A') → 'cat':3A 'fat':2A,4A 'rat':5A |
| setweight ( vector tsvector, weight "char", lexemes text[] ) → tsvector | သတ်မှတ်ထားတဲ့ weight ကို — lexemes argument ထဲမှာ စာရင်းပြုထားတဲ့ — vector ရဲ့ elements တွေဆီ သတ်မှတ်ပေးပါတယ်။ lexemes argument ထဲက strings တွေကို lexemes အနေနဲ့ — နောက်ထပ် process လုပ်ခြင်း မရှိဘဲ — မူရင်းအတိုင်း ယူပါတယ်။ vector ထဲက lexeme တစ်ခုခုနဲ့မှ မကိုက်ညီတဲ့ strings တွေကိုတော့ လျစ်လျူရှုပါတယ်။ | setweight('fat:2,4 cat:3 rat:5,6B'::tsvector, 'A', '{cat,rat}') → 'cat':3A 'fat':2,4 'rat':5A,6A |
| strip ( tsvector ) → tsvector | tsvector ကနေ positions နဲ့ weights တွေကို ဖယ်ရှားပါတယ်။ | strip('fat:2,4 cat:3 rat:5A'::tsvector) → 'cat' 'fat' 'rat' |
| to_tsquery ( [ config regconfig, ] query text ) → tsquery | Text ကို — သတ်မှတ်ထားတဲ့ (သို့) ပုံသေ configuration အတိုင်း စကားလုံးတွေကို normalize လုပ်ပြီး — tsquery အဖြစ် ပြောင်းပေးပါတယ်။ စကားလုံးတွေကို valid (တရားဝင်) tsquery operators တွေနဲ့ ပေါင်းစပ်ထားရပါမယ်။ | to_tsquery('english', 'The & Fat & Rats') → 'fat' & 'rat' |

## Conclusion (နိဂုံး)

PostgreSQL မှာ — ဒီ tutorial မိတ်ဆက်မှုထဲမှာ မပါခဲ့တဲ့ — feature တွေ အများကြီး ရှိပါသေးတယ် — ဒီ tutorial က SQL ကို အသစ် စလေ့လာနေသူတွေအတွက် ဦးတည်ထားတာမို့ပါ။ ဒီ feature တွေကို ဒီစာအုပ်ရဲ့ ကျန်တဲ့ အပိုင်းတွေမှာ အသေးစိတ် ဆွေးနွေးထားပါတယ်။

နောက်ထပ် မိတ်ဆက် (introductory) ပစ္စည်းတွေ လိုအပ်တယ်လို့ ခံစားရရင် — နောက်ထပ် resource တွေရဲ့ လင့်တွေအတွက် PostgreSQL [web site](https://www.postgresql.org) ကို သွားကြည့်ပါ။

- [SQL အခြေခံ](/docs/postgresql/sql-basics) — tutorial တစ်ခုလုံးကို အစကနေ ပြန်စချင်ရင်

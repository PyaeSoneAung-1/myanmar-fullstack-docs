## အဆင့်မြင့် Features များ (Advanced Features)

ဒီ chapter (Chapter 3) က [SQL အခြေခံ](/docs/postgresql/sql-basics) (Chapter 2) မှာ လေ့လာခဲ့ပြီးသား အခြေခံတွေကို ဆက်ပြီး — SQL ရဲ့ အဆင့်မြင့် feature တချို့ကို မိတ်ဆက်ပေးပါတယ်။ ဒီ feature တွေက database တွေကို စီမံခန့်ခွဲရတာ ပိုလွယ်ကူစေပြီး — data တွေ ပျက်စီးခြင်း ဒါမှမဟုတ် မှားယွင်းခြင်းတွေကနေ ကာကွယ်ပေးပါတယ်။

ဒီ chapter ထဲမှာ section တွေ ခြောက်ခု ပါဝင်ပါတယ်:

## Section တွေ

- **3.1 Introduction** — ဒီ chapter ရဲ့ နိဒါန်း (ဒီစာမျက်နှာကိုယ်တိုင်ပါ)
- **3.2 [Views (မြင်ကွင်းများ)](/docs/postgresql/views)** — query တစ်ခုကို view အဖြစ် နာမည်ပေးပြီး သာမန် table တစ်ခုလို ပြန်သုံးနိုင်အောင် လုပ်ပေးခြင်း
- **3.3 [Foreign Keys (နိုင်ငံခြား သော့များ)](/docs/postgresql/foreign-keys)** — table တစ်ခုရဲ့ row တွေက တခြား table နဲ့ ကိုက်ညီမှု ရှိစေအောင် referential integrity ထိန်းသိမ်းပေးခြင်း
- **3.4 [Transactions (အရောင်းအဝယ်)](/docs/postgresql/transactions)** — SQL command တွေကို all-or-nothing အုပ်စုတွေအဖြစ် စုစည်းပြီး data ယုံကြည်စိတ်ချရမှု သေချာစေခြင်း
- **3.5 [Window Functions (ဝင်းဒိုး လုပ်ဆောင်ချက်များ)](/docs/postgresql/window-functions)** — row တွေကို စုစည်းမပစ်ဘဲ လက်ရှိ row နဲ့ ဆက်စပ်တဲ့ row အစုအပေါ် တွက်ချက်မှုတွေ လုပ်ခြင်း
- **3.6 [Inheritance (အမွေဆက်ခံခြင်း)](/docs/postgresql/inheritance)** — table တစ်ခုက တခြား table ရဲ့ column တွေကို အမွေရယူနိုင်ခြင်း
- **3.7 [Conclusion (နိဂုံး)](/docs/postgresql/conclusion)** — tutorial ရဲ့ နောက်ဆုံး အကျဉ်းချုပ်

- [SQL အခြေခံ](/docs/postgresql/sql-basics) — Chapter 2 ကို ပြန်ကြည့်ချင်ရင်
